# Tendhearth CC desktop v1.8.6

**Date**: 2026-11-21
**Tag**: `desktop-v1.8.6`(配套 CLI 同号)
**Scope**: 宽窗口里点左边一行,右边就是这件事自己的那条线。

---

## 点进一件事

- **右边是这件事自己的线。** 你说的、agent 回的全文、它做的几步,从上到下。不再是筛过的 CC 对话加几张卡片。
- **标题行**是这个地方的名字,后面一句小字写正在看的这一次是谁、什么状态(「Claude Code · 停着 / 正在做 / 等你定 / 已经结束」)。没有「回到全部」了:回去点最上面「CC 在家」那一行,或者后退。
- **好几次会话时**,线的上方多一排可以换着看;只有一次时不出现这一排。进来先看在等你定的那一次,没有就看最近动过的。
- **它做的几步收成一行**「做了 N 步」,点开一步一行;正在跑的时候写「正在做,已经 N 步」,并露出最新那一步。
- **等你定的那一件**在线的最下面、紧挨输入框,就地允许 / 不允许。在一件事的页面里,顶上只留这件事自己的纸条,别处的不跟过来(左栏的圆点和 CC 那一句还在)。
- **输入框直接接着它说**,前面写着在对谁说。现在说不了的时候输入框会写明原因:它正在做又没有开着的窗口、在等你定、已经结束。
- **往上有更早的**:线的最上面有「更早的」,点了往前载,读的位置不跳。
- 交办的任务也在这一页里看,用的是原来工作台那一套。
- 后退 / 前进记得你在哪个地方看着哪一次。
- 窄窗口和手机不变。

## 底下改的

- **agent 的回复存全文了。** 原来每一步只存前 600 个字,现在另存一份全文(最多 4 万字)。只对这一版之后新记下的步生效,之前的仍是前 600 字。
- **一次会话能往前翻。** 原来只拿得到最近 40 步。

## 读到一半的位置

- 把窗口拖窄、拖宽,或者从一件事换回和 CC 的对话,读到一半的位置留在原处。1.8.5 里「拖窗口边改宽度时位置可能轻微移动」那一条一并修了。

## 已知

- 这一页发版前只在测试环境里验过(全量界面测试 + 逐屏截图),没在打包好的窗口上验。
- 已经结束的会话仍会从左栏消失,它的线也就翻不到了。要不要留着能翻,还没定。
- 正在跑、又没有开着窗口的会话,话送不进去,要等它这一轮停下来。
- 一页里长回复特别多时,全文会被均匀截短。
- 交办任务那一种的排版和输入区还是工作台自己的,和终端会话的线不完全一样。
- 「把一件事画成图」还没进程序。
