# wechat-cc desktop v1.7.2

**Date**: 2026-10-02
**Tag**: `desktop-v1.7.2`(配套 CLI 同号)
**Scope**: 修好打包版丢插件(wxvault 自 09-11 起失效);记忆当天就能用上;桌面界面按 Tendhearth 设计统一;手机 app 的电脑端全部就位(手机 app 本身还没上架);一批稳定性修复。

> 走 patch:按 roadmap「每合一批就发一版」。距 1.7.1 四天,里面有一个正在影响使用者的问题(插件丢失),所以不再等。

---

## 修好:打包版找不到内置插件

09-11 起后台改由 .app 拉起之后,打包版 daemon 一个内置插件都没加载 —— wxvault(微信记录)、客户回顾、wxsearch 全部静默失效。现在:

- 插件来源登记在状态目录里,启动日志与 `/v1/health` 都会报出加载了哪些插件。
- 部署时插件少了会直接失败并回滚,不会再一声不吭。

## 记忆:早上说的事,下午就记得

此前有了长期记忆 `memory.md` 之后,白天新告诉 CC 的事要等当晚 04:00 整理完才看得到。现在 CC 白天记下的新内容会进一份「今天的草稿」(最多 600 字),每个对话都带上;当晚整理时并入长期记忆并清空。草稿只有后台能写,任何会话都改不了它。

桌面上原来叫「重新整理」的按钮改名为 **「更新项目地图」** —— 它重算的是项目地图,和微信里的「整理记忆」不是一回事。

## 桌面:Tendhearth 设计统一

- 全衬线、一个强调色、不换深色;桌面与手机用同一套色板。
- 浮窗桌宠:CC 够得着就亮(以前只在正在聊时亮)。
- 「鱼缸」页退休;「浮到桌面」移到此刻页连接面板,连接状态提示移到设置的「连接」区。
- 「N 件事等你」直接写出问题或要批准的命令,不再只给任务标题和数量。
- 内置中文衬线字体做了子集化(常用 7635 字),桌面包小约 2.7 MB;生僻字回退到系统字体。

## 手机 app 的电脑端(app 尚未上架)

Tendhearth 手机 app 还在验收,未上架。这一版先把电脑端需要的部分全部带上,对不用手机 app 的人没有可见变化:

- 新的加密中继协议 v2 与推送(默认关闭,只有在 `agent-config.json` 里设了 `relay_v2_url` 才会使用)。
- 一次性配对码,桌面「连接手机」直接出码,手机与桌面显示同一个核对码。
- 手机上跟 CC 说话、交办、批准、接着做电脑上的 Claude Code / Codex 会话、额度用完交给另一个执行者。
- 手机重发不会重复执行(按请求号去重)。

## 其他修复

- 工作台:原生会话的文件夹是符号链接时也能导入 / 接着做(在真实目录里带记录新开)。
- 工作台文件层:修了两个能让附件写到项目外面的竞态,威胁模型写进文档。
- 断点续传:粗精度文件系统上(Windows / HFS+ 等)同一时刻的外部改动不会再被漏检。
- Windows:关库后数据库文件不再被占着(影响关库后紧接着删除 / 改名的操作)。
- Cursor 额度耗尽不再被当成正常回复。
- 自改:新增 `wechat-cc self change --abandon <id>`,回收不再接着做的运行占的工作树。

升级会跑一个数据库迁移(v70:手机「说一句」的请求回执),自动完成,不动已有数据。

**对使用者可见的变化**:插件恢复、记忆当天生效、桌面界面与按钮名。手机 app 相关的部分要等 app 上架后才用得到。
