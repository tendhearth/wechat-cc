# Tendhearth CC desktop v1.8.10

**Date**: 2026-11-25
**Tag**: `desktop-v1.8.10`(配套 CLI 同号)
**Scope**: 「等你定」看得清楚；模型一时忙不过来时 CC 不再哑十分钟；桌面按钮跟手机统一；窄窗口也用宽窗口那一套；微信里的回复说人话；设置里加了日历开关。

主人 11-22 说审批那一页「可读性很差」。这一版把桌面、微信、手机网页上所有「等你定」的地方，都改成先把要批准的东西画出来：命令是一块、改文件是增删行、写着在哪个目录执行。看不全的时候不让直接批。

---

## 「等你定」：要批准的东西画出来

- **画成什么样。** 命令放在一个有底色的块里，前面一个 `$`；改文件是路径加增删行（红的删、绿的加）；网址、搜索、键值各有写法。下面一行写「在 <目录>」（这一轮实际在哪个目录执行）。执行者给的原因、CC 的意见在下面。想逐字核对，点「看完整原文」。
- **看不见的字符标出来。** 命令或改动里夹着回车、把字倒过来显示的控制符、零宽字符时，写成看得见的转义，并提示一句。
- **在哪些地方。**
  - 任务详情的审批区。有东西等你定时这一块给够地方：对话区让位（窗口矮时干脆收起），输入框收成一行，按钮贴在审批区底部，不用滚就点得到。点「允许这一步」失败时，提示写在标题下面，不会被收起的对话区盖住。
  - 宽窗口对话上方浮着的纸片：命令最多 4 行、改动最多 4 行。
  - 点进一个终端会话时底下那张卡片（原来只有一行「工具名 · 摘要」）。
  - 窄窗口「此刻」里终端会话的弹框。
- **看不全的时候不能直接批。** 内容被截了、只有换行或空白的差别、带着卡片上看不到的脚本、或者不知道在哪个目录执行时：
  - 纸片上「允许这一步」换成「打开看全再定」，点进去看全了再批。
  - 终端会话的卡片和弹框上只有「先不做」，旁边写「这里看不全，请到终端里看全再定。」
  - 「先不做」任何时候都能点。

## 微信里的权限提示

- 原来是三行原文。现在是「谁要做什么」，加上命令块或增删行和目录，回「y 码」「n 码」照旧。
- 卡上看不全、或者要跑卡上看不到的代码（脚本、`bash -c` 里带的代码、`npm test` 这类会跑项目脚本的简写）时，只能回「n」拒绝，并说明到电脑或手机上看全再定。
- 引用一张卡回复时，只算那一条请求，不会批到同一件事后来的请求。
- 主动提醒和以前一样不带原文；完整的请求照旧可以凭提醒上的码批。

## 手机网页的审批卡

- 补上了执行目录、额外参数（比如「后台运行」）、看不见的字符。
- 看不全时只留「先不做」，请你到手机 App 或电脑上看。

## 按钮跟手机统一

桌面上原来同一个动作有「允许 / 拒绝 / 不允许」几种说法、两种左右顺序。现在六处（任务详情、纸片、终端会话卡片、窄窗口的弹框、窄窗口一件事的详情、桌宠的批准卡）都是 **先不做** 在左、**允许这一步** 在右（主按钮），和手机一样。

## 窗口窄的时候也用宽窗口那一套

窗口在 760 到 900 宽之间时（把 CC 放在终端旁边分屏常落在这里），原来换成另一套顶栏版式。现在和宽窗口是同一套：

- 900 宽以下左栏默认收起；点左上角的按钮或者把鼠标移到左边就出来。你在这个宽度里手动展开过，就照你的来。
- 后厨这类左右两栏的页，窄了改成上下排。
- 输入框下面那排按钮保持一行。
- 把页面放大到很大（⌘+）时，展开的左栏浮在正文上面，不再把正文挤没；窗口很矮时，左栏底部的「更多」一直点得到。

## 模型一时忙不过来时，CC 不再哑十分钟

原来 Claude / Codex 第一次用之前会先单独「探」一下；那一下要是刚好碰上服务端一时过载（529），之后十分钟里每一句都直接回一句错误，还叫你去终端查版本、确认登录。现在不再单独探，第一句真实的回复就是确认；出错时按原因告诉你：一时忙不过来（稍后再发一句就行）、账号或密钥被拒、额度用完、或者真的是版本 / 模型不合。下一句照常发出去。「CC 的连接」里能看到这次是刚确认过、还是沿用上次的结果。

## 小的

- 设置的「偏好」里多了「读日历和提醒」的开关（原来只能在微信里打「日历 开」）。只读；开了以后早报会带上今天的日程。
- 微信里的命令回复改成大白话：/help、/mode、/solo、/stop、还没接上某一家时的提示、/set、/health，以及微信号被别处重新绑定时的通知；小标题不再带微信显示不出来的星号。
- 交办的事等你批时，左栏项目那一行和纸片的标题不再是「Bash: command=…」，改成「想运行 …」「想改 …」。
- 左栏「在做」名单读到之前不再先写「在做 0」。
- 终端会话没报自己的目录时，卡片上不再把项目名写成「项目目录」。
- 意见那一行的括号改成全角：「我的意见（只看了这条请求）」。


## 已知

- 这一版的界面只在测试环境里验过（Mac mini 上全量界面测试、每一页每种状态逐张看截图），没在打包好的窗口里验；测试用的是 Chrome 的内核，桌面应用本身用的是 Safari 的引擎。
- 「读日历和提醒」的开关需要这一版的桌面应用本身：应用里带着一份允许访问的接口清单，这次多了两条。正常更新就是整包换，不用另外做什么。
- 「CC 的连接」里「已确认 / 沿用上次的结果」在少数情况下会记到别的模型名下（一轮进行中换了模型、运行中升级了 CLI、Codex 中途改路由）。只影响这一页的显示，对话照常。
- 没有新的数据库迁移。手机 App 的改动（字、查漏两轮、本子的信、等你定那一页、首页那一行说人话、连接页的确认状态）跟 TestFlight build 7 走，不在桌面包里。
