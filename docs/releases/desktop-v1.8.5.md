# Tendhearth CC desktop v1.8.5

**Date**: 2026-11-20
**Tag**: `desktop-v1.8.5`(配套 CLI 同号)
**Scope**: 用了 1.8.4 之后的六处打磨:正文第一眼看到;左栏名字和内容分得开;后退 / 前进;全屏时按钮贴左;收起的行能放回来;点进一个项目总有东西看。

---

## 读起来

- **日期让开正文。** 日期行居中、变小变淡,每一天的第一条上面都有;顶上不再固定写着今天的日期。阅读栏的左边线上只剩头像和正文。
- **打开时停在最新一条。**
- **「更早的对话」挪到对话的最上面**,翻到头才看得见,不再压在正文上方。只看一个项目时,往前确实可能有它的话才出现;点了会一直往前找,找的时候写着「在往前找…」。原来这种情况下点了没有反应。

## 左栏

- **名字是名字,内容是内容。** 名字永远是这一行最重的;下面那一句不再加粗:还没看过的用深色,看过的用浅色。选中一行时,其它行不再整体变灰。
- **收起的行能放回来。** 名单末尾多了「收起的 N 处」,点开是收起的那几个名字,每个后面一个「放回来」,点了回到它原来的位置。

## 点进一个项目

- 顶上是这个项目的名字和「回到全部」。
- 这个项目的事和终端里的会话会作为卡片列出来,点卡片就能看过程、接着说。原来只有终端会话的项目点进去是空的。

## 窗口左上角

- **后退和前进。** 侧栏按钮右边多了两个箭头:点进一个项目、去本子或记忆、打开一件事,都能一步步退回来,也能再前进。快捷键 `⌘[` / `⌘]`(Windows 上 `Alt+←` / `Alt+→`),鼠标侧键也行。
- **全屏时贴到最左。** 红黄绿按钮不显示的时候,这三个按钮从窗口最左边起。

## 已知

- 用绿色按钮进出全屏时按钮位置的切换,发版前只在测试环境里验过,没在打包好的窗口上验。
- 拖窗口边改宽度时,读到一半的位置可能轻微移动。
- 本子、记忆、回忆等其它页面还没按「正文第一」重新排过。
