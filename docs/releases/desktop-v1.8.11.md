# Tendhearth CC desktop v1.8.11

**Date**: 2026-11-26
**Tag**: `desktop-v1.8.11`(配套 CLI 同号)
**Scope**: 「等你定」的说法更像人话（工具名不再露英文、意见那一行）；CC 没在运行时「等你定」说清楚为什么点不了、就地能叫它起来；「CC 的连接」记得更准、插件用自己的名字；设置和插件页的说法；桌面上不再出现 daemon / dashboard。

这一版没有新功能，全是 1.8.10 之后看界面、截图时挑出来的毛病。

---

## 「等你定」说人话

- **工具名不再露英文。** 请求只带一句摘要时，原来卡片标题写「Codex 想用「Read」」、左栏写「想用 Read：读备份目录？」。现在常见的几类都有说法：「想看一个文件」「想看看文件夹里有什么」「想在文件里找东西」「想打开一个网址」「想上网搜一下」「想派一个帮手去做」「想改一个笔记本」。认不出的、外接服务的工具照旧写原名。「看完整原文」里照旧有原始工具名。
- **同一件事挂着几条请求时分得清。** 大白话后面带上路径、网址或搜索词。
- **左栏那一行说现在等的这件**，不再停在上一条进度。
- **意见那一行**改成「我只看了这条请求，意见是：……」。原来「（只看了这条请求）：」两个全角标点挨着，中间空出将近一个字。
- **微信里查任务状态时，等你定的请求只写域名或文件名。** 带签名的下载链接、像「TOKEN=…」这样的路径不会因为查个状态就进了聊天记录；完整内容要明确「查看 … 权限」才给。

## CC 没在运行时

- 「等你定」纸条和终端会话卡上的按钮原来只是灰掉、点了没反应。现在按钮下面写着「CC 没在运行，叫它起来以后才能回答。」后面就是「叫它起来」；CC 回来以后这一行自己收起。
- 「叫它起来」在纸条、一件事的页面、会话卡里都能点；叫的时候页面上所有「叫它起来」一起变成「在叫…」，叫不起来的提示出在你点的那张卡上。
- 「叫它起来」终于是强调色，空地方的「去和 CC 说」终于画成按钮——原来按设计写好了，但被一条公共样式压住，一直是灰字。这类毛病（样式里 id 和类混写把整条规则的优先级抬高）一共清了 32 处，并加了检查不让再写出来；改动前后各截了 98 张图逐像素对过，只差时间戳。

## 「CC 的连接」

- 「已通过对话确认连接 / 沿用上次的结果」记到这一轮**实际答话**的那个模型和 CLI 版本名下：一轮进行中换了模型、运行中升级了 CLI、Codex 中途改路由，都不会再记错。查版本号也不再挡回复。
- 「来源」里的插件用它自己的名字：「微信语义搜索」「语音转文字」，不再写 wxsearch / wxmedia。

## 小的

- 设置里「自动同意工具调用」改成「自动同意 CC 的每一步」，说明写成「关掉后，CC 每读一个文件、跑一条命令，都要你在微信里回 y 或 n」。开机自启的说明去掉重复的一句。
- 后厨的插件页读不到时说「插件列表加载失败，点「刷新」再试」「市场暂时打不开，过一会儿点「刷新」再试；也可以用上面的「手动添加插件」」，不再叫你去改环境变量。
- 桌面上给人看的文字里不再出现 daemon / dashboard（引导、停止按钮、插件、日志、诊断、微信号被别处绑定时的系统通知……），排查用的命令照留在后面。

## 已知

- 这一版的界面在测试环境里验过：Mac mini 上全量界面测试（Chrome 内核），另外用系统自带的 WebKit（和桌面应用同一个引擎）把主要页面截了一遍和 Chrome 逐张对照，只差字的抗锯齿、焦点框和原生下拉框的样式。没在打包好的窗口里点过。
- 三张以上「等你定」纸条、从第三张叫 CC 起来、叫的过程中又把列表收起：叫不起来时那张卡没画着，失败提示就没处显示，再展开也不会补上。下次点「叫它起来」或 CC 回来时照常。
- 某个对话**显式**选了 Codex 推断出的默认模型、启动又在报出目标之前就失败时，「CC 的连接」可能还显示上一次的确认。只影响显示。
- 手机网页的「等你定」详情卡还写原工具名（网页包的大小放不下那张表）；名单那一行已经是新说法。
- 没有新的数据库迁移；原生壳（`src-tauri`）没动。配套 CLI 同号。手机 App 的改动跟 TestFlight build 7 走，不在桌面包里。
