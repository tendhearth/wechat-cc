# Tendhearth CC desktop v1.7.9

**Date**: 2026-11-08
**Tag**: `desktop-v1.7.9`(配套 CLI 同号)
**Scope**: 1.7.8 之后十天:和 CC 就是一段对话,事情按话题自己归好;CC 主动开口更克制、只在一个地方提醒你;底下一件事只有一条线、路由一族收成 `/v1`。

---

## 打开就是和 CC 说话

- 桌面打开就是和 CC 的那一段对话。交给执行者去做的事,在对话里就是一条消息,做完结果回到对话里。
- **话题**:CC 会把聊过的事按话题归好(比如某个项目)。再聊到时,对话上方冒出这个话题的泡泡,带上以前记下的决定、进展、结论;换了说法也能认出来。
- 睡一觉(CC 每晚整理)以后泡泡自动收起,再聊到时重新打开。对话上方有一行话题,点一下就切过去。
- 话题可以改名、合并、删除,某条记错了可以标「不对」。
- 「此刻」和「一起做」合成一个主页:一种行、一套状态词,桌面、手机网页、App 一致。

## 提醒只在一个地方

- 一件事做完 / 没做成:你在电脑前时只在桌面提示,10 分钟没看再推到 App。
- 在桌面看过了(详情、前台做完、桌宠),手机就不再推。
- **点桌面系统通知,直接打开那件事**,并记成看过(macOS)。第一次会请求通知权限。
- CC 主动开口(信、见闻、明信片、贴纸、提醒……)共用一个预算,大约 20 小时一次挑最值得说的那一句,不再各说各的。待说的话重启不丢、过期就不说了。

## 桌宠

- CC 有了更多动作和道具,会按真实在做的事动起来;拖动改成跟手(Mac)。
- 桌宠改为订阅变化,不再每两秒问一次。

## 更稳

- 一件事只有一条时间线(对话的每一轮、执行者的每一步、终端会话都在上面),各端读同一份,状态不再各算各的。
- 手机、桌面调 daemon 的路由收成一族 `/v1`,旧路径成了别名;按 30 天调用记录确认没人用了才删。本版起桌面请求带版本号。
- 记忆整理连着几晚失败(模型把输出预算全花在思考上)已修,并换了默认模型。
- 回合内的快速判断独立选快模型,不再等慢的 CLI。

## 升级须知

- **数据库迁移 v91 → v110**,升级后第一次启动自动完成;其中 v102 删掉旧的 `matters.status` 列(不可逆,数据已搬到时间线)。
- 第一次有事要提醒时,macOS 会请求通知权限。
- 桌面内部改调 `/v1/matter/*`,行为不变。
- 手机 App 的「一段对话」界面随 App build 3 发;手机网页随 daemon 已经是新版。
