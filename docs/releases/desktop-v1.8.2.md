# Tendhearth CC desktop v1.8.2

**Date**: 2026-11-19
**Tag**: `desktop-v1.8.2`(配套 CLI 同号)
**Scope**: 1.8.1 之后两天:主界面换成「上面是现在，下面是说话」,并按主人试用后的意见打磨了一轮;CC 不再把随口的点子当成交代;后台不会再被卡住的系统工具拖死。

---

## 上面是现在，下面是说话

- 首页上面一列是「地方」:你交代过事的每个项目一行,位置固定,不按状态跳来跳去。一行只有名字、一句现状和时间——圆点是在等你,加粗是它说了话你还没看,时间写「现在」就是正在干。
- 等你批准的,在那一行上直接点「允许 / 不允许」;要你回答的点「去回答」。宽窗口时这些按钮就跟在同一行末尾。
- 点一行,下面的说话只剩这件事,最上面写着「只看 X · 回到全部」;再点一次回到全部。CC 的回复上方标着它属于哪件事,点名字也能筛过去。
- 每行的「⋯」里可以往上挪、往下挪、收起这一行,只在鼠标停在那一行时出现。
- 输入框前面写着在对谁说,打字时自动长高;语音输入和朗读回复变成两个小图标。顶栏只剩 CC 和「CC 在家」,切到别的页面时头像角上亮一个点,表示有事在等你。
- App 和手机网页同样换成了「地方」这一套。

## CC 说话

- 随口说的点子(「以后可以加个收藏」)CC 只记下,不开工;拿不准时先当点子。
- 交办出去之后,CC 会说清楚放到了哪一件事上。

## 更稳

- 系统的进程列表工具偶尔会整机卡住;以前这会把 CC 后台一起卡死,现在 CC 在后台读进程表,卡住时有上限地放弃,照常响应。
