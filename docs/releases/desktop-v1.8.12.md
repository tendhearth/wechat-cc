# Tendhearth CC desktop v1.8.12

**Date**: 2026-11-27
**Tag**: `desktop-v1.8.12`(配套 CLI 同号)
**Scope**: 终端会话能一键「到终端」；「CC 现在怎么样」显示 Claude Code / Codex 额度；认出接上 hook 之前就开着的会话；批准卡上「以后这类都不用问」；微信回「y 码」要先看过完整的卡。

这一版对着 Perch 那类「管终端 agent」的工具补了四样电脑上用得着的东西。

---

## 到终端

- 「等你定」卡上的终端会话、点进一件事里的终端会话头，多了一个「到终端」。点了跳回那个 Claude Code / Codex / Cursor 会话所在的窗口。
- 能跳到哪一层看终端：iTerm2、Terminal.app、Ghostty、tmux、WezTerm 能到具体的标签或 pane；kitty 要先开远程控制。VS Code / Cursor 把那个项目的窗口提到前面；Warp 和其它终端只把 app 叫到前面。
- 第一次控制 iTerm 或 Terminal 时，macOS 会问「是否允许 Tendhearth CC 控制」。拒了也能用，只是只把 app 叫到前面，按钮旁会提示去系统设置里允许。
- 只有这台 Mac 上开的会话才有这个按钮；手机和网页上没有。
- 位置是会话开始时记下的：这一版之前就开着的会话要重开一次才有按钮。

## 额度

- 「CC 现在怎么样」里，Claude Code 和 Codex 各多一行额度：5 小时和本周各一条细线，写着用了多少、什么时候重置。过了 80% 换强调色，用完了写什么时候恢复。读不到就不显示。
- 只在打开页面时读一次，不在后台一直问；同一家读失败后五分钟内不再试。

## 接上 hook 之前就开着的会话

- Claude Code / Codex 只在会话启动时读 hook 设置，所以开 hook 之前就开着的会话 CC 一直看不见。现在「电脑上的会话」里会列出这类最近还在写的会话，写一行淡字「开 hook 之前开的，重开这个会话才能接上」。
- 它们不推送、不进日报，也没有批准、送话这些按钮。两小时没动静就不再列出。

## 以后这类都不用问

- 同一个项目里，同一类请求你连续亲手批了三次，第四张卡上会多一个「以后这类都不用问」，并写出要加的那条规则。点了，这一次照常批准，同时记下一条只管这个项目、这个工具、这条命令开头（或这个文件）的规则。中间拒过一次就重新数。
- 目前只有 `bun test …`、`pwd`、`git status` 这几类命令和项目里已有的文件会出这个按钮；带管道、`&&`、重定向这类的都不出，红线（sudo、密钥、对外请求、改规则文件本身……）永远不出。
- 桌面、桌宠和手机 App 的卡上有；微信里没有，照旧 y / n / yt。最近 24 小时加的规则会列在日报里，不要了用 `wechat-cc rules rm` 撤。

## 微信回「y 码」

- 微信的主动提醒为了隐私不带命令原文。原来回「y 码」就批了——没看到批的是什么。现在：这条请求的完整卡没在这个微信会话里收到过，回「y 码」先把完整的卡发给你，看完再回同一个码才批。看过卡的照旧一次就批；「n 码」随时一次就拒。

## 已知

- 这一版的界面在 Mac mini 上跑过全量界面测试、看过截图；手机 App 的几处在模拟器上走过。「到终端」在测试机上用假的执行器验过，**没在主人的电脑上真点过**（会抢走当前窗口），第一次点时请留意系统的授权框。
- 「接上 hook 之前」的会话靠对话记录最近有没有写入来判断：直接关掉、没留结束标记的会话可能还会列出一阵，最多两小时。
- 带新规则（「以后这类都不用问」写的那种）的规则文件，退回旧版本后旧版 CLI 编辑不了，会报错停下，不会把规则放宽；旧版读的时候直接跳过这几条。
- 有一个新的数据库迁移（v123，终端会话的位置）。原生壳（`src-tauri`）里多了 `POST /v1/cli/focus` 这条路由的白名单，桌宠批准卡能带上「以后这类都不用问」。配套 CLI 同号。手机 App 的额度行和「以后这类都不用问」按钮跟 TestFlight build 8 走。
