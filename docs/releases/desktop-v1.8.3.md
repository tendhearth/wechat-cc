# Tendhearth CC desktop v1.8.3

**Date**: 2026-11-20
**Tag**: `desktop-v1.8.3`(配套 CLI 同号)
**Scope**: 1.8.2 之后一天:桌面宽窗口换成两栏,右边是一页纸的样子;每件事先说你上次看过以后变了什么;交办这条路走得通了。

---

## 桌面像桌面:左边是现在,右边是一页纸

- 窗口够宽时分成两栏:左边一列是每件事现在怎么样,右边是和 CC 说话。窗口窄的时候还是原来的上下叠。
- 左上是 CC 本人,旁边一句它对你说的现状,例如「两件要你定，一件在做。」。每件事前面的点:绿点是在等你,暖光慢慢亮暗是有人在做,没有点是安静。这周没动的收在末尾一行,点开还在原来的顺序。
- 右边没有标题栏,从日期开始;对话跨天的地方有一行日期。
- 要你定的事是 CC 递过来的纸条,钉在最上面,直接在上面答。
- 说话不用气泡。CC 用它自己的头像;你的头像先是一张「还没画」的铅笔稿。CC 的回复属于哪件事,名字写在那句话前面,点它只看那件事。「干了几步」是一行小字,点开是缩进的几行。
- 输入的地方不再是方框:你的头像后面一条线,在线上写。
- 点左边一件事,右边只看它,日期后面跟着「只看 X · 回到全部」;记忆、回忆这些页面显示在右边,左边那一列一直在。

## 坐回来

- 每件事的那句现状,会先说你上次看过它以后变了什么;除了这一句,还有几件也动过的,会一并说「另有 N 件也动过」。桌面、App、手机网页都有。

## 交办

- 你没点名谁来做时,CC 用你默认的执行者,确认卡上照样写清是谁。
- 交办没成时,CC 用平常话告诉你卡在哪、你可以怎么办。
- 「随口的点子不开工」和「直接说要做什么就交办」这两条,用真模型反复跑过并据此改了 CC 的提示词:登记了的项目上,该交办的 15 次里对 14 次;不该交办的 15 次里只有 1 次误交办。

## 已知

- 「现在」那一列里看得到、但还没登记成工作项目的项目,CC 暂时不能按名字把活交过去,会告诉你它没登记。下一版让它在确认卡上顺手登记。
