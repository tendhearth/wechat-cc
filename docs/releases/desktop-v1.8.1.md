# Tendhearth CC desktop v1.8.1

**Date**: 2026-11-18
**Tag**: `desktop-v1.8.1`(配套 CLI 同号)
**Scope**: 1.8.0 之后一周:CC 当你的总管家——一段对话、旁边一列「在做」;谁答的这句看得见;Grok 免费接入;一件事可以交给几个 agent 接力,也可以分享给别人一起聊。

---

## 主界面:一段对话 + 「在做」

- 中间始终是和 CC 的那一段对话;旁边一列「在做」,列出正在做的事和电脑上的终端会话,等你批准或回答的排在最上面。
- 点名单里的一项,就在原地直接和那件事 / 那个 agent 说话,点返回回到和 CC 的对话。窄窗口时名单收进右上角的「在做」。
- 左边只留搜索、记忆、回忆和「⋯」;原来的话题行和「N 件事等你」收进了名单和记忆页。
- App 和手机网页同样换成这一套:顶部一排头像就是「在做」,点进去直接说。

## 这句是谁答的

- 你可以直接说「让 Codex 回答…」「这句给 Grok」,CC 会把这一句交给它;说得不清楚时 CC 会先问一句,答错了说一声就改。
- 回复旁边露出实际代答的那一家的小圆标(桌面、App、网页一致);CC 自己组织的回复不加标,微信里代答的会带 [名字]。

## Grok:免费接入

- Grok 成为内置执行者,用你自己的 Grok 账号(免费、有额度上限),登录只在 CC 专属的目录里,不碰你平时的 Grok。
- 设置里「连接其他 AI 服务 → 登录已有账号」选 Grok,点「安装并登录」,CC 会打开看得见的终端跑官方安装器,浏览器里授权一次就接上。
- Grok 现在也能用 CC 的工具(微信、记忆、记录本等),权限和其他执行者一样按你的设置。
- Grok 连不上网时不会反复重试;这一句改由 CC 来答。

## 一件事交给几个 agent

- 一件事可以挂多个 agent,共用一本记录;CC 可以把活拆成几棒,你批准一次后做完一棒自动派下一棒,每一棒用一行状态收尾。
- 电脑上的终端会话也能挂进一件事,记录和详情放在一起看。

## 分享一件事

- 可以把一件事分享给合伙人一起聊:对方打开链接就能看进展、说一句,CC 会回应他,需要时提议转告你。开链接前会在确认卡上问你。

## 管家体检

- 新增本机「管家体检」:像一场面试,看当前用的模型记不记得住、做事靠不靠谱,结果只留在你电脑上;开始前会先告诉你大概的花费。

## 更稳

- OpenAI 兼容网关的偶发错误在出字之前会有界重试,不再整轮失败;超长对话会自动换段。
- 连接手机不用再改配置:统一中继,点「连接」即开通。
- 对话会话令牌不再出现在子进程的命令行参数里。
- 设置抽屉里点接入选项不会再把抽屉关掉;窗口很矮时隐私说明弹窗不再被顶栏挡住。

## 升级须知

- 升级后布局会变化:原来的话题在「记忆 → 话题」,等你处理的事在「在做」最上面。
- 想用 Grok:升级后在设置里登录一次即可。
