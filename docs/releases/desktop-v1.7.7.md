# Tendhearth CC desktop v1.7.7

**Date**: 2026-10-15
**Tag**: `desktop-v1.7.7`(配套 CLI 同号)
**Scope**: CC 管起你在终端里开的 Claude Code / Codex,以及 Cursor 里的 agent —— 看得见、批得了、接得上，桌面、手机、微信三处都能用。

---

## 终端里的 Claude Code / Codex,CC 都管着

- 你在普通终端里开的 Claude Code / Codex 会话，CC 都记着：在跑、等你批准、歇着、结束了;重启 CC 也不丢。
- Cursor(编辑器里的 agent 和 `cursor-agent`)也能接上：做完、新的一句、结束都看得到，也能「看 码」「@码」接着说;批准仍由 Cursor 自己问你。
- 「CC 现在怎么样」里多了一行「终端里的 Claude Code / Codex / Cursor」:没接上点「接上」,接线坏了点「修复」;只在你点了才改 Claude Code / Codex / Cursor 的 hooks 配置，随时可以撤掉。

## 在哪都能管

- **手机**:「一起做」里并排显示终端里的会话;等你批准的可以直接「允许 / 拒绝」,歇着的可以接着说一句。做完、等你批准会推到手机，点开就到那条会话。
- **微信**:发「终端」看会话列表(等你批准的在前，带回复码);发「日报」看过去 24 小时:等你的、做完的、在跑的、可能卡住的。也可以直接问 CC「我终端里那几个在干嘛」。
- **桌面**:「此刻」的「N 件事等你」里也列出终端里等你批准的会话。

## 一眼看完今天

- 手机「此刻」顶上一块「过去 24 小时」,终端会话和一起做的事合在一起看。

## 更稳

- 微信拒收 CC 的消息时，终端会话的批准请求照样能在手机上拍。
- 你在终端前自己答完的权限，不会再挂成「等你批准」;已经过去的批准码会作废，手机不会对没人在等的请求回「已批准」。
- 会话还在跑(包括长时间构建)时，手机和微信都不会再插一句进去抢同一条会话。
- 设置链接只能看，不能替你批准或对终端会话说话。

## 升级须知

有一步数据库迁移(v76,只新增终端会话表),升级后第一次启动自动完成。无需重新授权。已经用 `wechat-cc hook install` 接过的不用重接。
