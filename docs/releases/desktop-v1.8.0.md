# Tendhearth CC desktop v1.8.0

**Date**: 2026-11-10
**Tag**: `desktop-v1.8.0`(配套 CLI 同号)
**Scope**: 1.7.9 之后两天:话题就是你的项目;把活交给 CC 不再卡住;桌面与 App 长成一家;CC 会看你、会接话。

---

## 话题就是你的项目

- 对话上方那行话题,现在就是你在做的项目:标签上直接看得见那个项目里有终端会话在跑、有事等你、或做完你还没看。
- 「等你」只算真正要你动手的事(批准、回答问题);终端里已经答完的不算。
- 在新开的 Claude Code / Codex 终端会话里,CC 会把这个项目记下的决定和进展带进去(只在能确定是哪个项目时才带)。
- CC 自己的例行流水不再记进话题。

## 把活交给 CC

- 交给执行者去做的事不再卡在临时目录、依赖安装、最新起点上;输出再多也不会把任务掐断。
- 批准卡:要跑的脚本内容直接显示在卡上(密钥打码);「允许这一次」总是有效。只有确认安全的系统命令才多一个「本任务同命令放行」。
- 拒绝一个操作时可以写一句理由,执行者带着理由换个做法继续,不再整件失败;连续被拒 3 次才停下来等你。
- 部署 / 重启时会先等在跑的活到可中断点;万一被打断,确认旧的执行者已退出后自动接着做一次。
- Codex 的连接确认(`/hooks` 信任)CC 会看出来、引导一次,确认后自动显示已连接,升级后不再重复要求。

## 桌面与 App 一家

- 对话页、详情、设置、记忆、CC 的连接:桌面和 App 用同一套分组、用词和行样式;展开收起只有一种 ›。
- 删记忆、断开连接、解除配对这类操作的确认只加强(写清后果、取消在前)。
- 记忆页不再露出内部文件名。

## CC 更像在身边

- CC 会按真实发生的事做小反应:你打字时抬眼看输入框,它在想、在说话时有对应的样子,做完有个小反应,新话题冒出来时朝那边看一眼。没有真实信号就不演,同一个动作有冷却,系统设了「减少动态」时换成静止画面。
- 新的眼神 / 说话帧沿用原来的形象,没有改 CC 的样子。

## 更稳

- 发版的 DMG 外壳本身也公证并 staple 了(离线首次打开不再提示)。
- 修了 Codex 任务答完后被误判超时、文件夹被锁的问题。

## 升级须知

- **没有数据库迁移**。
- 已经在用 Codex 终端会话的,首次打开可能看到一次「确认 Codex 连接」的引导,照着在 Codex 里 `/hooks` 信任一次即可。
