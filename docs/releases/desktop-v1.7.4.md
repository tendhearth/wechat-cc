# wechat-cc desktop v1.7.4

**Date**: 2026-10-04
**Tag**: `desktop-v1.7.4`(配套 CLI 同号)
**Scope**: 桌面 app 改叫 Tendhearth CC;重启通知不再打扰;不再反复弹「访问其他 App 的数据」;桌面语音输入能用了。

> 走 patch:三个主人反馈的问题,修好即发。

---

## 桌面 app 显示为 Tendhearth CC

程序坞、菜单栏、窗口标题、关于、权限弹框里的名字都改成 **Tendhearth CC**。这次只改显示名:安装位置(`/Applications/wechat-cc.app`)、命令行 `wechat-cc`、配置与数据目录、bundle ID 都不变,所以已经给过的系统授权都不用重新给。安装位置与进程名的改名在下一版单独迁移。

## 重启通知

- 计划内的重启(更新、部署、空闲时自动重启、手动重启)不再在微信里通知。
- 只有真正的意外重启(崩溃、被系统杀掉、断电)、并且离线超过 2 分钟时,才发一句「CC 刚才意外重启了一次(大约 N 分钟没在线),现在已经恢复。」—— 6 小时内最多一条,不带技术细节。
- 不再「补发」过时的重启通知。

## 不再反复弹「Tendhearth CC 想访问其他 App 的数据」

原因:后台每 5 分钟同步一次微信历史,需要读微信的数据。9 月 28 日之前给的「完全磁盘访问」对不上现在的签名,系统就改弹「访问其他 App 的数据」,而那个「允许」只对当前进程有效,每次重启都会再弹。

现在没有完全磁盘访问时,后台同步直接跳过、不再弹框,健康检查和 `wechat-cc doctor` 会提示。**要恢复微信历史同步,请一次性**:系统设置 › 隐私与安全性 › 完全磁盘访问,把 Tendhearth CC(旧版本显示为 wechat-cc)用「−」删掉,再用「+」重新添加 `/Applications/wechat-cc.app` 并打开开关(只关开开关不够)。

## 桌面「语音输入」能用了

1.7.1 起 app 用开发者证书签名后缺了麦克风声明,系统静默拒绝麦克风、按钮点了没反应。现已补上;第一次点「语音输入」时系统会问一次,点「允许」即可。被拒绝时界面会说清楚原因。

## 升级须知

无数据库迁移。
