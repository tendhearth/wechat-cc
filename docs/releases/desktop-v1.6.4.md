# wechat-cc desktop v1.6.4

**Date**: 2026-08-29
**Tag**: `desktop-v1.6.4`(配套 CLI tag `v1.6.4`)
**Scope**: 稳定性与信任小版本 — 隧道自愈、后台 LLM 用量大降、agy 工具链首次真正接通、提醒时区/迟到闭环、一批「界面不再撒谎」修复。

> 升级即直接重装,状态目录不动、无需重新扫码。agy 用户注意:升级后 daemon
> 首次启动会重写 `~/.gemini/config/mcp_config.json`(命名空间迁移),之后
> agy 会话才有微信工具。

## 稳定性 / 安全

- **隧道心跳自愈**:过公司代理被静默掐断的僵尸连接能自己恢复(用户实测
  手机连不上的场景);任何数据帧都算「活着」,pong 被代理拖慢不再误杀
  活跃会话;畸形/非绝对路径干净丢弃,不误路由、不产 unhandled rejection。
- **poll-loop 毒丸防护**(两轮):畸形 update、`item_list` 里的 null 元素
  都不再让机器人静默卡死。
- **附件落盘路径穿越防护**:userId 参与路径拼接处补齐校验(任意文件写入)。
- **审批送不达快速失败**:不再整轮卡死 10 分钟(用户反馈的 P0)。

## 后台 LLM 用量大降(ingest 清扫收敛)

伴侣记忆的三个后台清扫器(冲突判定/义务去重/承诺了结)此前对「判过但
无动作」的库存每 25 分钟原样重判——静止状态也稳定烧 ~5 次调用/轮
(约 280 次/天,每次都是完整的 agy 冷启动 + OAuth 往返;重启电脑后偶发
的 Google 登录页弹窗即源于此)。现在每次判定记录内容指纹(facts.db 新
`judge_state` 表),库存没变零调用跳过;feed 超量取,积压(63 组冲突、
24 个义务重联系人)会被真正消化一遍然后整体归静;了结回填的闸从
「30 天内有消息」收紧为「上次判定后有新消息」。

## agy:32 个微信工具首次真正可用

真机日志证实 agy 的 wechat MCP 从上线起就没连通过:命名空间
`wechat-cc:wechat` 的冒号让 agy 按 `^[a-zA-Z0-9_-]{1,64}$` 拒收了全部
32 个工具,agy 会话一直靠纯文本兜底(不能 reply/贴纸/记忆)。命名空间
改为 `wechat-cc-wechat`,boot 一次性迁移旧键,graceful shutdown 同时清理
新旧键。修复后实测同款调用工具拒收 32 → 0。

## 提醒:时区与信任闭环

- 信封给 CC 本地时间(带时区偏移)而非 UTC——钟点推理不再整点差 8 小时;
  「连续 N 天」改用系统本地日,旅行不漂移(留手动时区口子)。
- 主人设的提醒绝不因票据过期被丢弃(保持 pending 等主人回来即送);
  迟到的提醒会说明它迟了;完成划掉遇到 `ok:false` 不再假装成功。
- 待办提醒选择器点外面/按 Esc 能关掉;迟到/紧迫度体验若干。

## 语音兜底

语音读不了时给 CC 一个能懂的信号(不再对着占位符瞎回应);语音回复
发送失败时自动转文字补发,回复不再消失。

## 桌面端「不再撒谎」

- 设置抽屉/设置页:持久化失败的开关会回滚并提示(两处),不再静默假成功。
- 首装接大脑:openai 兼容接口缺 base_url/model 不再假成功;国内/本地自
  配大脑不再被网络体检误锁在「先开代理」墙后。
- 更新失败的「稍后会再试」成真;大脑体检失败可就地重试;PWA 图标尺寸
  对齐真实像素。
- 下载页重做(熊做主角),GitHub Release 绑定为下载单一事实源。
