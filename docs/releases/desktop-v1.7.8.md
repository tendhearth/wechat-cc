# Tendhearth CC desktop v1.7.8

> 草稿:合进 dev 的、主人看得见的变化先记在这里,发版时由整合者补全日期 / Tag / Scope 和其余各节。

## 设置

- 设置里清空 Cursor / agy 的路径,现在等于「自动找」,不再等于「不用」。以前微信对话那边会当成不用,「一起做」那边又会去找,两边说法不一;现在一样了(3c 第 2 步)。

## 照实说

- 在微信里发 `/codex`、`/agy`(或让 CC 帮你切过去)时,会多一句「提醒:它不会逐条问你,删东西也不会。」这两家没法在每条命令前停下来问你,以前切过去时没说;现在说清楚,你再选(Policy 第 2 步)。
