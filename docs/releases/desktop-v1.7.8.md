# Tendhearth CC desktop v1.7.8

**Date**: 2026-10-29
**Tag**: `desktop-v1.7.8`(配套 CLI 同号)
**Scope**: 1.7.7 之后两周的全部积累:CC 管得更多(定时、早报、日历、做过的事、放行规则),「一起做」能回到某一轮、行评论、两家对比,记忆你改了就算数;底下整个 daemon 重新收成一套清晰的结构。

---

## CC 自己会安排

- **定时**:在微信里说「定时 早报 8:00」,每天早上一条早报,取代当天零散的问候;也能「定时」别的事。手机 App 设置里能看、停、开、删。
- **周报**:每周回顾 CC 这一周做了什么、各执行者用了多少。
- **日历和提醒**:CC 能读你的日历和提醒事项(只读),发「日历」看,早报里也有一块。第一次会弹系统授权;不授权就读出空的,不报错。
- **CC 做过的事**:微信「做过的事 今天 / 本周」,手机 App 设置里有时间线。
- **免打扰时段**:`/set 免打扰 23:00-8:00`。CC 主动说的话(信、提醒、来访、早报、社交通知……)都认它和「别烦我」;别人写给你的不会被吞掉,等你方便时再说。
- **不主动提的话题**:`/set 别聊 …`。
- **此刻**:顶上一块「你不在的这 N 小时」。

## 一起做

- **回到某一轮**:桌面和手机都能把一件事退回到之前某一轮,改动一起撤回。
- **行评论**:审阅改动时可以对某几行写评论、按块撤回,一起发回去;手机上也能整块评论。打回时可以「同时记成这个项目的经验」。
- **审阅时标出该多看一眼的文件**(写「注意 · 原因」),桌面和 App 都有。
- **做到条件成立为止**:交办时写「直到这条命令通过」,它会一直做到通过;详情里有进度行。
- **额度用完**:回「等恢复」,额度恢复后自动接着做一次。
- **每件事花了多少额度**,详情里一行看到。
- **两家对比**:微信「任务 新建 <项目> 对比 @a @b <要求>」,两家同时做,「任务 对比 <编号> <编号>」并排看改动。
- **换一家来审**:「任务 <编号> 请 @codex 审」。
- **从 GitHub issue 开工**:「任务 新建 <项目> issue N」。
- **项目经验**:「经验 <项目> …」记下这个项目的规矩,哪家执行者来做都照着做;手机网页能看 / 加 / 删。
- **工作区脚本**:独立工作区可以配 setup / run / archive 脚本和端口,桌面、手机都能运行、停下。
- 每件事记下是从哪儿开始的(桌面 / 手机 / 微信),头像组旁边有个小记号;执行者都换成圆头像。
- Gemini(agy)在你当前网络出口地区用不了时,照实说「这个执行者在你现在的网络出口所在地区用不了」,桌面选执行者时也标出来。

## 放行规则

- 你可以定「哪些操作不用每次问我」的规则(默认关)。微信里「放行规则关掉 / 打开」。红线(删系统文件、往外连网等)永远照旧问你。
- 你自己的微信对话也按这套规则:按规则放行时,回复里会说一句「按规则『…』放行了」。
- **Codex 对话改成逐条问你**:危险命令会停下来问,不再直接执行(主人对话)。
- 切到 `/codex`、`/agy` 时会提醒一句「它不会逐条问你」(工作台里这两家仍是免审)。
- 重启前挂着的拍板卡,重启后会告诉你一次「作废了,还要再说一次」。

## 记忆:你改了就算数

- 桌面「记忆」页可以逐行编辑你自己的记忆;你写的单独列在「你写的」。
- 说「这条不对」收回的话,全链路都不再用,并且有「收回的话」列表可以看、可以恢复(桌面和 App)。
- 手改 `memory.md` 也会被识别成更正。
- 微信「导入记忆」:把别的助手对你的了解贴进来,你点头的才记;记忆带出处。

## 手机

- App 成了 CC 主动找你的第二条路:CC 发的图、表情、语音、信都在 App 里。
- 系统分享面板「分享给 CC」(文字 / 链接 / 图片);按住说话;发送和说话合成一颗按钮。
- 实时看终端会话在做什么,点开一步看 diff / 命令输出;手机对终端会话说一句会真的送进开着的窗口,等电脑确认了才说「已送进」。
- 手机上逐文件审阅:没问题 / 退回。
- App 补上待办和「CC 画的你」。
- CC 的轻动效、图标反馈、录音计时。
- **手机网页**收成「配对 / 此刻 / 一起做只看状态」,其余都在 App 里。

## 收敛(主人 10-21 定)

- 微信里不再开 `/both`、`/chat`:会回一句「多模型讨论在桌面上开」。
- 「客户回顾」删掉了:开机不再连 wxvault。
- 打猎改成**新装默认关**;已经在用的不变。
- 三端执行者叫法统一。

## CC 的信

- CC 不定期写一封信寄到微信,也可以当面说「给我写封信」。

## 更稳

- 整个 daemon 重新收成一个模块容器:各功能自己启停,可选的功能起不来只降级、不拖垮开机;关机按顺序停干净。
- 回复交付只剩一条路:每一轮最后的话就是回复,不再双发、不再漏旁白(五家执行者一致)。
- Codex 对话换成 app-server 协议(和工作台同一条),SDK 那条删掉。
- 配置文件读不出来时拒写,不再用空配置覆盖;桌面会说人话。
- 记忆、联系人事实全部进主库,开机自动导入,核对不过不搬。
- 一起做里机器忙时不再误报「这个项目不是 Git 仓库」;Codex 关闭时不再漏进程。
- 等拍板的那一轮在跑时,微信里回「y / n」当场生效。
- 账号被顶替的通知只发给主人。
- 访客的 Claude / Codex 会话一律按本次的权限模式,不再被 `--dangerously` 带成 bypass。

## 升级须知

- **数据库迁移 v77 → v91**,升级后第一次启动自动完成;其中会把记忆文件(`memory.md` 等)和联系人事实(`facts.db`)导入主库,原文件留着。第一次启动会比平时慢一点。
- **手机网页要重新扫码一次**:网页改走中继 v2,老的连接方式(协议 v1 + 老中继)退休,旧页面会提示「连接方式升级了，请在电脑上重新扫码配对」。配置里只有老中继的,「CC 的连接」会提示在「连接手机」里重新配对。原生 App 不受影响。
- 第一次发「日历 开」时 macOS 会请求日历和提醒事项权限;拿到授权才打开。日历标题会交给回你话的那个模型。
- 已接过的终端会话 hooks 不用重接。
