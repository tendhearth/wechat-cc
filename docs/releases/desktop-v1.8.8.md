# Tendhearth CC desktop v1.8.8

**Date**: 2026-11-22
**Tag**: `desktop-v1.8.8`(配套 CLI 同号)
**Scope**: 宽窗口换成「干净的一版」;小结;一轮查漏(别的页面、CC 没在运行、搜索、菜单)。

---

## 宽窗口换了样子

窗口够宽(900 像素以上,默认开出来就是)时的主窗口。只动样子,功能和按钮一个没少。窄窗口、手机网页、手机 App 不变。

- **纸和桌面。** 窗口的底和左栏是桌面的颜色,右边是一张浅一号的纸。
- **左栏。** CC 缩小,不再有光晕。搜索、本子、记忆、回忆从最底下挪到 CC 下面。每个项目一行:名字,下面两行说它现在怎么样。「更多」在最底下。
- **一件事。** 标题行是名字、agent、一个状态标记(等你定 / 正在做 / 停着 / 已经结束)。
- **对话。** 每句话前面的头像去掉了。你说的在右边浅底的框里;agent 说的是正文;CC 说的用 CC 自己的手写字。等你定的卡片、输入框各是一张浮起来的纸片。
- **字。** 只有两种:CC 写的、说的用它的手写字,其余是系统的无衬线字。等宽只留给路径和命令。
- **图(实验)** 跟着换了:铺在点阵纸上,说明卡浮在左下角。

## 小结

一件事聊了几轮、你半小时没来,CC 留一段话:这件事在干什么、停在哪、下一步是什么。

- **在哪看。** 左栏那一行名字下面;点进那件事,在线的最下面有一张手画框的便条,写着「你 38 分钟没来,CC 留了张条」。你在那件事里再说话,或者定了等你定的请求,便条就收掉。
- **什么时候有。** 这次会话里你说过至少 3 次话;这一轮做完了(停在等你批准也算);最后一次动静过去 30 分钟,这 30 分钟里你没在桌面上点开过它。
- **谁写的。** Claude Code 的会话用它自己记的那段(便条上写「这是 Claude Code 自己记的」),CC 不调模型。别家的会话,或者 Claude Code 那边没记的,由 CC 调一次便宜的模型来写:走私密通道,只读这次会话最近几轮,每次会话每天最多 8 次。
- **能关。** 设置 →「偏好」→「小结」,默认开。关掉以后不写、不读、不调模型。
- 小结只显示在这两处,不写进 CC 的记忆。窄窗口和手机不显示。

## 查漏

- **CC 没在运行时,右边不再说「CC 在这儿」。** 换成暗的 CC 和一个「叫 CC 起来」的按钮。它回来之前,发送键和等你定的卡片上的按钮不能点,打好的字留着。
- **搜索是纸上正经的一页**,不再是盖在对话上、把对话切掉一半的面板。加了快捷键 ⌘K(Windows 是 Ctrl+K),再按一次或按 Esc 回到刚才那一页。
- **别的页面**(本子、记忆、回忆、待办、画室、后厨)用同一张纸、同一套标题和按钮;内容居中,不再有东西伸到纸外面。后厨三页同一个标题。
- **设置**(宽窗口)全部换成无衬线字。
- **菜单该关的时候关。** 点「更多」里的「设置」后菜单会关;「更多」和输入框左边「＋」的菜单按 Esc、点外面都会关。左栏的行菜单(「⋯」)开着的时候,左栏不会因为刷新把它关掉了——以前有 agent 在跑时,这个菜单几乎点不到。
- 等你定的卡片钉在对话上面时,对话从它底下滚过去的地方有了渐隐。

## 已知

- 这一版的界面只在测试环境里验过(全量界面测试、每一页每种状态逐张看截图),没在打包好的窗口上验。
- 小结用真模型验过,但用的是编的会话;拿你真实的会话写出来什么样,要你用了才知道。
- 搜索还是只搜交办的任务和项目,搜不到会话和对话里的话。
- 窄窗口(拖到 900 像素以下)除了搜索和行菜单,还是原来的样子,和宽窗口是两套。
- daemon 重启会忘掉「你刚在桌面上看过哪件事」,所以重启后可能提前给刚看过的事写一条小结。
- 已经结束的会话仍会从左栏消失(同 1.8.6)。
