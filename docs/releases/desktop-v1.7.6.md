# Tendhearth CC desktop v1.7.6

**Date**: 2026-10-14
**Tag**: `desktop-v1.7.6`(配套 CLI 同号)
**Scope**: 同一个项目并行做几件事(独立工作区);任何会说 ACP 的 agent 都能接进「一起做」;手机上能做的事补齐一大截;首次安装的向导更清楚;一批安全与稳定性修复。

---

## 同一个项目，并行做几件事

- 交办时可以选「独立工作区」:每件事在自己的 git 工作区里做，互不干扰。
- 做完可以「提交到分支」「合回项目」(只做快进合并，别的情况交给你决定)、「删除工作区」;归档时干净的工作区会顺手收掉，删了的还能「重新打开」接着做。
- 「另做一份」:同样的要求交给另一位执行者并行做，挑好的那份。
- 可以「从分支开始」;项目里的 `.worktreeinclude` 列出的本地文件(如 `.env`)会一起带进工作区。
- 桌面、手机、微信(`任务 <编号> 提交 / 合回 / 删除工作区`)三处都能操作。

## 更多 agent

- 「一起做」可以加自定义 ACP 执行者：任何支持 ACP 的命令行 agent 都能接进来，需要登录的会走它自己的登录流程，失败时显示 agent 给的原因。

## 手机上能做的事

发图、停下正在跑的一轮、看成果(图片 / 文字在 app 里看，PDF / 网页交给系统打开)、搜和 CC 的对话、交办时选模型与思考强度、换「跟 CC 说」用的后端、看「CC 记得你」并逐条纠错、打开 CC 回复里的文件。

## 桌面

- 「此刻 / 一起做」重新分家：每样东西只有一个位置;此刻里能拖进或粘贴截图、文档。
- 「CC 现在怎么样」:一页看清各项能力是好的、受限、没配还是坏了，手机上也有同一份。
- 一起做的任务回复了或停下了会弹系统通知;「改动」面板可以逐文件撤销。
- 首次安装的向导：显示第几步，分得清 CLI「装了」和「登录了」,Gemini(订阅)、Cursor 判断与后台一致;后台服务那一步出错时说清楚原因和该点哪个按钮。

## 安全

- 桌面窗口只许在 app 自己的页面和预览框之间跳转，别的链接一律拦下。
- 访客：多家模式的每一位参与者都过档位门;Codex 不对访客开放;`--dangerously` 不再把访客提成管理员。
- 来访有上限，和朋友聊天时不再带上你的概要;介绍来的名片不能覆盖已有朋友。
- 记忆页安全渲染 markdown;插件数据与状态目录只有你能读。

## 稳定性

- Google 下线 gemini-3.7 后后台判断全部失败：默认改成 3.8,模型名再被拒时会自己换到同一档的新型号。
- 每晚整理记忆：模型抄错编号不再让整晚失败;一时连不上当天会再试几次。
- 中继、微信收消息、提醒在断网时退避，不再一下失败就判死;微信拒收的消息不再重试。
- 工作台「没确认退出」改按进程组判断，重启后能自己解除。
- 打包版的知识库向量化可以真正使用。

## 升级须知

有三步数据库迁移(v73–v75,只加字段与表),升级后第一次启动自动完成。无需重新授权。
