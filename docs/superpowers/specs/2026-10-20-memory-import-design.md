# 从别的助手导入记忆 —— 设计

> 2026-10-20 · 第二轮对标 #7(Claude 的 import memory:给一段话贴到 ChatGPT / Gemini,把回答贴回来)。主人 10-20 `/loop`。目的:上手第一天 CC 就认识主人(降上手门槛)。

- 微信「导入记忆 [来自哪]」⇒ CC 回一段让主人贴到那边的话(一行一条、只写确知的、不写密码证件这类)。30 分钟内主人把回答贴回来 ⇒ 本机确定性拆分(列表行优先,否则按句;去重;最多 20 条;每条 ≤200 字;像密钥 / 密码的行丢掉;按关键词猜一节,猜不出就「关于你」)⇒ 编号列出来。
- 主人回「全部 / 1,3 / 不要」⇒ **只写点过头的**;写之前什么都不存。重复的、主人纠正过的(corrections.md)、超出记忆总长的都跳过并说清。
- 写法:与每晚整理同一条串行链(`importEntries`),不走 applyNightly(避免顺手触发过期);出处记成 `{kind:'import', excerpt:'从 X 导入'}`;memory-log 记一行(「CC 做过的事」里显示「整理了记忆:新增 N 条」)。手机「CC 眼中的你」点开一条显示「从 X 导入」。
- 等粘贴时收到的不像清单(拆不出两条)⇒ 当普通聊天放过,不吞话。只认主人。
