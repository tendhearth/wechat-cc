## 权限与运行

新增 `GET /v1/companion/thoughts` 为 admin 路由。原生桌面通过已有受限 host 代理读取，页面不获取 operator 凭据。响应只含条目 ID、时间、标题、原文，不包含聊天 ID、候选或提示上下文。损坏文件报 503，文件不存在是空历史。

开发服务从同一台机器的固定状态目录只读此文件，拒绝 cross-site 请求；mock 模式不读实际文件。这使旧 daemon 下也能预览。正式使用新增日记接口需同时更新 daemon 与桌面端。

## 样板落实修正

用户指出首轮只做了入口归类，未采用确认的 `art/cc-presence-entry/preview.html` 布局。本次将样板作为正式页面的布局基准：

- 177px 左侧导航，主入口为此刻 / 一起做 / 回忆；原页面收到左下角生活与工具，连接设置保留。
- 此刻使用居中的冻结 CC、真实当前活动及底部交流区。直接复用原聊天通道；旧 converse 入口回到此刻并聚焦同一个输入框。页面切换不清草稿，不自动发消息，不用示例画作假装正在作画。
- 一起做采用两栏；首先显示本轮执行助手的真实最新回复，成果文件在同一页内。完整执行记录与可选服务/命名默认折叠。助手身份、任务文件夹及状态可核对，未生成 CC 复核结论。
- 展开状态按任务隔离；刷新保留输入、展开状态、阅读位置和折叠栏键盘焦点。执行服务的摘要跟随真实选项，而不是全局默认值。
- 回忆保留真实图文与收藏功能，以日期、文字及小图排列，按需打开完整内容。
