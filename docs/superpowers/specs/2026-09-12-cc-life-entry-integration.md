# CC 此刻与回忆：第一阶段接入

用户确认：此刻只显示 CC 当下活动，过去的画、明信片和日记归入回忆；一起做的专业执行闭环随后单独推进。

## 已接入

- 主导航收成此刻、一起做、回忆；旧画室、记忆、聊天、待办、觅食、后厨仍在「生活与工具」。设置入口保留。
- 此刻使用已有 `/v1/companion/presence`。闲着就是闲着，不拿最新 journal 标题模拟活动。chatting 信号实际代表三分钟内入站，所以文案是「刚刚在和你聊」。读取失败或 60 秒没有新样本后明确表示未知。
- 原鱼缸与连接诊断收在首页可展开区域，原事件处理和 ID 保留。
- 明信片册从觅食移动到回忆，复用原收藏、全文弹窗和图文导出。觅食保留直达明信片的入口。
- 画作读取现有 atelier 接口，显示最近 24 幅的图、时间与创作手记；未接通和真实空记录区分处理。
- 日记与想法读取原 plan-log 中最近 14 个有记录的日子，只呈现 source=model 且有原文的选择；不把 fallback、降级或失败记录写成角色自述，不宣称计划已经执行。按天折叠，全日原文可展开。
- 串门见闻读取最近 500 条 journal 中不带图的 visit；带图故事归明信片。「关于你」进入原记忆页。
- 分类别读取，较慢的旧请求不能覆盖新分类。没有写回或搬动原始记录、没有自动分享或生图。

## 权限与运行

新增 `GET /v1/companion/thoughts` 为 admin 路由。原生桌面通过已有受限 host 代理读取，页面不获取 operator 凭据。响应只含条目 ID、时间、标题、原文，不包含聊天 ID、候选或提示上下文。损坏文件报 503，文件不存在是空历史。

开发服务从同一台机器的固定状态目录只读此文件，拒绝 cross-site 请求；mock 模式不读实际文件。这使旧 daemon 下也能预览。正式使用新增日记接口需同时更新 daemon 与桌面端。

## 本轮验证

真实只读开发页面验证：此刻状态、3 张已有明信片、4 个有想法的日期、折叠展开、空画作状态、原鱼缸与连接入口。浏览器未出现 console error。没有实际切换模型、改收藏、发送消息或改用户记录。

测试覆盖来源失效、空与失败区分、范围切换竞态、按天折叠、内容转义、图片来源、私有请求经 host 代理及只返回原始想法；另运行桌面测试、相关接口与 schema 测试、全仓 typecheck、cargo check。审查发现并修复原生 operator routeAllow 漏接与菜单被旧导航 overflow 裁切；补充真实 HTTP 请求测试，确认 operator 可读且 trusted 被拒绝。实际鼠标点击确认工具菜单可进入原画室。
