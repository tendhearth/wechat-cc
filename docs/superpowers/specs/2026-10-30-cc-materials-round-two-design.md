# CC 第二批素材：视角与动作道具组合

2026-10-30。主人要求继续做素材，并明确不需要中途询问。沿用已有 CC 设计；本稿中的具体数量、视角和实现方案由实施者选择，不记作主人已经验收的新美术。

## 目的

补齐同一个 CC 的立体观察资料，并让已有动作和道具能放在一起审查。不是重复生成已经完成的十段连续动作，也不靠增加装饰数量来充数。

当前基础：13 个行为；十段连续片共 132 对采样、264 张角色 PNG 与 132 张共享 mask；489 项注册素材；八种 C 姿态研究；七件已获美术验收的道具。真正缺口是正面、侧面、背面、俯仰资料，以及连续动作中道具和脸部、脚底的关系。`canonical/front` 实际是已有三分之四视角，继续原字节保留。

## 选择

考虑过增加随机表情、重新生成角色、沿冻结模型补资料三条路。选择第三条：造型、材质、灯光和既有播放语义保持一致，新增材料的作用清楚，也能回查来源。使用 Blender 的可编辑原生模型渲染；不以生成图片替换冻结角色。

本批只做素材研究及审查工具，不替换日常 CC 的默认素材、不自动晋升美术状态。所有新增材料标为 `production-candidate` / 非运行时研究。

## 交付

1. **20 对真实新视角。** 水平 16 方向：方位角 0 至 337.5°，步长 22.5°，俯仰 0°。另外正面及左前三分之四（315°）各做抬高观察 15° 与 30°。共 40 张角色 RGBA PNG 和 20 张逐对共享 mask。坐标：0° 面向模型 −Y，90° 从 +X 看右侧，180° 从 +Y 看背面。旧三分之四图只作为明确标注的既有参考，不计作新帧。
2. **小尺寸及双底对照。** 每个视角在 48、96、128、256px、纸色和石板色底上并排看 Light/Dark。离线页支持按视角选看、手动播放水平环视；俯仰图是观察样张，不伪称运行时动作。减少动态和隐藏页会停止播放。
3. **五组动作与道具样张。** working+laptop，thinking+mug/thought-bubble，permission+exclamation，receive+envelope，look+micro-light。沿用当前完整片段、fps、循环/单次语义与真实道具槽位；不造未读数字、任务完成事实或新的常驻表演。输出联系表、可重播双态样片及来源摘要。组合页明确是美术对照，不代表实时任务。

## 不变的合同

- 一个 C、两眼两脚，无嘴、耳、手、尾。Light 表示 daemon 够得着，Dark 表示够不着，与背景主题无关。
- 512×512 RGBA8，anchor `(256,470)`，safe bbox `[80,28,432,470)`。逐对实体 mask 共用；实体不透明区 alpha 不减，外部 alpha ≤89，Dark alpha 等于实体 mask，无外部雾。
- 冻结 `.blend`、原相机对象及数据、材质、灯光、canonical、既有动作、mask、manifest 和旧检查点全部保留原字节。新相机复制对象与 camera data，不在原 `.blend` 保存。
- 相机围绕 `(0,0,1.65)`、半径 10.5。全部新视角使用同一正交比例，至少 3.85；若投影边界需要放大，整批共同调整，不逐图缩放或按视觉效果居中。先按脚底投影登记，再用真实不透明覆盖探针处理控制顶点与求值后轮廓的抗锯齿差异：只允许相机沿上方向修正最多两像素，实际记录修正量；最终仍须第 469 行有覆盖、下一行无覆盖。不平移或裁切输出图片，不水平居中脚的包围盒。
- 背面/侧面允许真实遮挡眼睛；两只眼的几何仍必须存在。冻结渲染器的“每图白眼可见”和固定屏幕接触阴影只适用于原视角，不照搬到背面。使用独立研究适配器，在内存中派生渲染函数，明确记录两处差异；原脚本及运行时验证不改。正面仍验证白眼可见，侧背遮挡单独记录。
- 全部测试、渲染、浏览器截图在专用 Mini。主机只轻量编辑、传输和读素材，不开预览窗口或接管输入。Mini 不运行真实 CC 后台、不接账号；渲染及验证保持进程级离线限制。公开 Blender 工具下载单独标识。

## 验收

先以正面、右侧、背面及正面抬高 30° 低采样试渲染确认注册和遮挡，再以 96 samples、seed 11 完成正式候选。每对检查格式、完整解码、共享覆盖、边界、脚底和无雾；记录相机、采样、工具与源码摘要。错误或不完整结果不得当作已完成检查点，重跑只信校验后的记录。

组合图从现有 `prop-layer.js` 的槽位取值，先与真实 DOM 边界对照；逐帧检查不盖住 Dark 的白眼。联系表保留全序列；单次行为可停尾帧重播，隐藏或减少动态不会补播。最终独立检查只报影响结果的错误。素材经实施者视觉检查仍不等于主人美术验收。
