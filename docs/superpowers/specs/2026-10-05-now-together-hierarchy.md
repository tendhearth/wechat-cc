# 此刻 / 一起做:层级与「每样东西只有一个家」

2026-10-05。主人反馈:「此刻、一起做,感觉对用户层级不是很明确,包括 iPhone、Mac 等等」,授权直接改、不打扰。本文是 `2026-10-01-tendhearth-design-unify-design.md` 的增补,规矩 §1(同一信息只出现一次)不变,这里把它落到两个主入口上。

## 1. 问题(改之前三端的实际样子)

| 东西 | 出现在哪 |
|---|---|
| 和 CC 的对话 | 桌面:此刻(chat 态)**和**一起做侧栏「对话」一栏(同一个控件来回搬家);手机:此刻(气泡 / 说一句)**和**一起做顶部置顶「和 CC 的对话」+ 一起做底部「跟 CC 说一句」 |
| 等你决定的事 | 桌面:此刻「N 件事等你」**和**一起做「等你处理」**和**除此刻外每页顶部横条「一起做 · 待你处理 N」 |
| 交办 | 桌面:一起做「交办」按钮;手机 app:**只能**从对话里「交给 CC 去做一件事」;手机网页 /m:放在**此刻** |
| 回忆 | 桌面:主导航一级;手机网页 /m:藏在**一起做**里 |
| 正在做的事 | 手机网页 /m:此刻焦点也放「一起做的事 · 查看进展」 |

另外两处让层级直接「断掉」:
- 桌面进「一起做」时把主导航整个收起,换成一起做自己的侧栏 + 顶部 `tendhearth` 按钮——看起来像进了另一个 app,和此刻 / 回忆不再是同级。
- 手机 app「一起做」标签点进去,页面标题却是「你和 CC」,空状态写「说过的话，做过的事，都在这里」——标签说的和页面说的不是一回事。

## 2. 定案

两个主入口各回答一个问题:

- **此刻 = CC 和你**:CC(明暗)、它最近一句话、和它的对话、现在要你管的事(等你决定 / 带回的成果)、CC 的生活(回忆、明信片)。
- **一起做 = 交给 CC 的事**:事情列表 → 一件事(进展、批准、成果);新的事从这里「交办」;把电脑上已有的会话接进来也在这里(放在末尾)。

规矩:**每样东西只有一个家**,别处最多一个指向它的数字或链接,不再画第二份。

| 东西 | 家 | 别处 |
|---|---|---|
| 和 CC 的对话 | 此刻 | 无(一起做里删掉) |
| 等你决定的事 | 此刻「N 件事等你」 | 主导航 / 标签栏「此刻」旁一个灰色数字;一起做列表里按状态排前(是排序,不是第二份列表) |
| 交办 | 一起做 | 对话里「交给 CC 做」保留(从一句话顺手交出去,是上下文动作) |
| 回忆 | 此刻那一侧(桌面主导航一级;手机网页挂在此刻下) | — |
| 正在做的事 | 一起做 | 此刻不放 |

## 3. 落地

**桌面(Mac)**
- 窗口 ≥1180px:一起做和此刻、回忆一样留在主导航下,三栏 = 主导航 / 事情列表 / 一件事。窄于此才把主导航收起,左上角 `tendhearth` 叫出(原行为)。`workbench-navigation.js` 的 `wideQuery`。
- 一起做侧栏删掉「对话」一栏,连同把对话控件搬进工作台的整套代码(`selectMatter`、`#wb-converse-host`、`mountConverse/unmountConverse`、`/v1/matters?kind=chat` 那次读取)。搜索框改「搜索任务或项目」。
- 顶部横条「一起做 · 待你处理 N」删掉;改为主导航「此刻」旁的数字(`#now-count`,= 此刻那张列表的行数,读不到 / 陈旧不写)。轮询与系统通知照旧(`createWorkbenchAttentionPoller`),只是不再挂横条。

**手机 app(iPhone)**
- 一起做:页面标题 = 「一起做」(和标签一致),空状态「交给 CC 的事会在这里。」;删掉置顶对话;底部条从「跟 CC 说一句」改为「交给 CC 做一件事…」→ 交办页;「电脑上的会话」挪到列表末尾。
- 标签栏「此刻」后面跟灰色数字(`waitingCount`,与此刻行数同一算法;不在线不写)。

**手机网页 /m**
- 「交给 CC 做」从此刻挪进一起做顶部;「回忆 ↗」从一起做挪到此刻(返回键「← 此刻」);删掉此刻的「去看看一起做的事 ↗」(底部标签已经有);此刻焦点不再放「正在做」的事。
- 已知缺口(有意不做):/m 没有独立的对话页,主人对话仍作为一件事出现在 /m 一起做列表里。/m 是没有原生 app 时的后备页,单独做对话页不值;原生 app 与桌面已按本文收口。

## 4. 不变
名字「此刻 / 一起做」不改(主人定的品牌词);设计 token、字体、CC 明暗、批准页与一件事详情页结构都不动;没有新接口。
