# 免打扰时段 —— 设计

> 2026-10-20 · 第二轮对标 #5(alfred_ 的 quiet hours:夜里不急的消息压着,急的照过)。主人 10-20 `/loop`。

- `/set 免打扰 23:00-8:00`(也认 `23-8`、`22:30~7:15`、`至 / 到`;`/set 免打扰 关` 清掉;英文 `/set quiet`)。按主人时区,跨午夜照常。**默认没设 = 不拦**(默认窗口由主人定,不替他定)。`/set` 总览里多一行「免打扰」。
- 时段里**不主动**:agenda 到期的那句、问候、打猎、串门、记忆这些伙伴主动消息(care tick 在任何登记之前拦,到期的 agenda 不打勾,时段过了照常发);不定期的信不写不寄(写好没寄的也等)。
- 时段里**照常**:主人自己定的提醒、定时 / 早报 / 周报,一起做的通知与权限卡,当面要的信。
- 存在主人那条对话的 chat prefs(`quiet: {from, to}`)。
