# 不改配置文件就能连手机 —— 设计

> 2026-10-24 · 状态:**主人 11-11 定稿**(见文末「主人定」)(改主人看得见的东西:桌面「连接手机」那一屏,和新装的缺省)。起因:主人想把手机版通过 TestFlight 分享给一位已经装了电脑版的朋友,而她要先手改 `agent-config.json` 加一行 `relay_v2_url` 才连得上。

## 为什么

今天的「连接手机」(配对体验设计稿 2026-10-01)在没配中继时诚实地显示「手机连接服务还没开通 / 开通之后,这里会出现二维码。」—— 诚实,但走不下去:开通的唯一办法是按 `docs/maintainer/relay.md` §8 手改配置文件。当时这样定,是因为生产中继还没上线(「上线前不碰生产域名」)。现在生产中继在跑(`relay.tendhearth.com/healthz` 200,10-24 核过),这道门该换成一个按钮。

对标:
- **Claude Code Remote Control**:终端里一条 `claude remote-control`,不开端口、只出站 HTTPS,手机 App 接着用。
- **Paseo / Happy**:桌面出一个码,手机扫,完了。没有「先去改配置」这一步。
- 共同点:**开通和配对是同一个动作**;说清楚流量走哪儿,但不让人去编辑文件。

## 做法(主人 11-11 定)

1. **点「连接手机」就是同意**。没开通中继时,不再显示「还没开通」那一屏,也不加单独的「开通」按钮:点「连接手机」⇒ daemon 写 `relay_v2_url: "wss://relay.tendhearth.com"` + 打开远程隧道 + 重启一次(现有 `starting` 那条路)⇒ 照常出码。审计一行(谁、什么时候开的)。
2. **界面上不加说明句**。二维码旁只放一个小的「隐私说明」链接,指向 `https://cc.tendhearth.com/privacy/`(已上线,里面写清了中继转发、端到端加密、读不到也不存)。
3. **写配置走 daemon 的新动作**(`POST /v1/phone/enable-relay`,operator 级、只局域网),读 → 合 → 原子写,不抹掉别的键;跟 `remote_tunnel` 开关同一种做法。已配过 ⇒ 幂等,直接出码。
4. **只认我们的中继**:写的是代码常量 `DEFAULT_RELAY_V2_URL`,不收参数。理由:App 推送只有我们的中继能发(APNs 密钥在我们的 Worker 上);统一中继也是以后 CC 之间互通的底座。
5. **自己搭中继先不放**:界面不提、用户文档不写。现有 `relay_v2_url` 手改配置的能力保留(代码不删),只是不对外说。
6. **新装缺省不变**:装上不自动连中继;只有主人去点「连接手机」时才开通。
7. 「先不连」/关掉那一屏 ⇒ 不写任何东西。

## 不做

- 不在微信里开通(微信那头只聊天、简单做事;连手机是在电脑前做的事)。
- 不自动探测「主人有没有手机」再提示。
- 不做自建中继的界面 / 文档。

## 测试

- daemon:新路由写 `relay_v2_url` 且原样保留别的键;非局域网 / 非 operator 拒;已配过 ⇒ 幂等。
- 桌面:没配过中继时点「连接手机」⇒ 调 enable-relay → `starting` → 出码,二维码旁有「隐私说明」链接、没有说明句;取消 / 关掉不写任何东西(Playwright,`phone-connect.spec.ts` 加两条)。
- 真机:一台没配过中继的机器,点按钮 → 手机扫码连上。

## 主人定(11-11)

- 统一用我们的中继(relay.tendhearth.com,即 Cloudflare 上那台);自己搭中继先不放。
- 点「连接手机」本身就是同意,不另设开通按钮;界面不加说明句,只放「隐私说明」链接(隐私页里写清楚)。
