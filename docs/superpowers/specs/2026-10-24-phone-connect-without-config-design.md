# 不改配置文件就能连手机 —— 设计

> 2026-10-24 · 状态:**草稿,待主人点头**(改主人看得见的东西:桌面「连接手机」那一屏,和新装的缺省)。起因:主人想把手机版通过 TestFlight 分享给一位已经装了电脑版的朋友,而她要先手改 `agent-config.json` 加一行 `relay_v2_url` 才连得上。

## 为什么

今天的「连接手机」(配对体验设计稿 2026-10-01)在没配中继时诚实地显示「手机连接服务还没开通 / 开通之后,这里会出现二维码。」—— 诚实,但走不下去:开通的唯一办法是按 `docs/maintainer/relay.md` §8 手改配置文件。当时这样定,是因为生产中继还没上线(「上线前不碰生产域名」)。现在生产中继在跑(`relay.tendhearth.com/healthz` 200,10-24 核过),这道门该换成一个按钮。

对标:
- **Claude Code Remote Control**:终端里一条 `claude remote-control`,不开端口、只出站 HTTPS,手机 App 接着用。
- **Paseo / Happy**:桌面出一个码,手机扫,完了。没有「先去改配置」这一步。
- 共同点:**开通和配对是同一个动作**;说清楚流量走哪儿,但不让人去编辑文件。

## 做法

1. **「连接手机」那一屏,没开通时多一个按钮**:标题照旧「手机连接服务还没开通」,正文换成一句说明 + 按钮:
   - 正文:「手机不在家里网络时,经我们的中继转发。内容在手机和这台电脑之间加密,中继读不到。」+ 一个「隐私说明」链接(`cc.tendhearth.com/privacy`,上线后)。
   - 按钮:「开通并显示二维码」。点了 ⇒ 写 `relay_v2_url: "wss://relay.tendhearth.com"` + 打开远程隧道 + 重启一次(现有的 `starting` 那条路),然后照常出码。审计一行(谁、什么时候开的)。
   - 「先不开」⇒ 关掉,下次再点「连接手机」还是这一屏。
2. **写配置走 daemon 的一个新动作**(`POST /v1/phone/enable-relay`,operator 级、只局域网),不是桌面直接写文件 —— 跟 `remote_tunnel` 的开关同一种做法(`remote-toggle.ts`),读 → 合 → 原子写,不抹掉别的键。
3. **只认生产地址**:按钮写的是代码里的常量 `DEFAULT_RELAY_V2_URL`,不收参数。要用自己的中继照旧改配置文件(高级用法,文档里写)。
4. **新装的缺省不变**:不默认开。开通是一个看得见、说清楚了的动作,不是装上就把流量送去我们的服务器。

## 不做

- 不在微信里开通(微信那头只聊天、简单做事;连手机是在电脑前做的事)。
- 不自动探测「主人有没有手机」再提示。

## 测试

- daemon:新路由写 `relay_v2_url` 且原样保留别的键;非局域网 / 非 operator 拒;已配过 ⇒ 幂等。
- 桌面:`relay_not_configured` 显示按钮;点了走 `starting` → 出码;「先不开」不写任何东西(Playwright,`phone-connect.spec.ts` 加两条)。
- 真机:一台没配过中继的机器,点按钮 → 手机扫码连上。
