# CC 动画素材与陪伴交互扩充

2026-10-29。用户要求连续推进八小时，扩充动画素材、对照其他产品并增加功能，中途不询问选择。本稿的取舍由实施者作出，不记作用户已经验收的新美术。任务窗口：2026-10-29 10:01 至 18:01 America/Los_Angeles。

## 目的与约束

让 CC 的动作表达真实的工作、等待和结果，同时让长期常驻更安静、入口更有用。沿用暖纸色、一个主要动作和已定稿的 C 形小团。Light 表示够得着 daemon；Dark 表示够不着，与系统主题、鼠标靠近或用户离开多久无关。

用户追加强调「CC 两种状态，之前的产品设计没有体现出来」。本批把双态提升为首要验收：每种动作都配套 Light/Dark，同页等尺寸对照。Light 的软瓷、内光与克制暖晕，Dark 的炭黑哑光、白眼与清晰轮廓，要在浅深背景和 48px 下分别读得出来；不能靠把页面改成深色来表现 Dark。连接场景展示「在身边 / 暂时没连上」及真实转换，而非只展示一列浅色表情。私有设计板只供核对，不复制到仓库或公开预览。

起点 dev `6a5fc89adbd73edb6e34f4d7579cf5f0f16b0ce8`。本批整合者为主执行者，整合区为 `codex/cc-animation-expansion` 的独立工作区。子任务各用自己的工作区。只在本批功能分支串行整合，不接管已被占用的 dev 工作区；共享部署、公开发版和推送 dev 留待既有整合安排。

角色保持一个 C、两眼两脚，无嘴、耳、手、尾。冻结 `.blend`、相机、材质、canonical 和旧资产保持原字节。新素材写新路径。每帧 512×512 RGBA PNG，anchor `(256,470)`，safe bbox `[80,28,432,470)`；两态对应帧引用同一路径实体 mask。实体 alpha 不被效果侵蚀，外部 alpha ≤89，Dark 不发光且无外部雾。

新帧标 `production-candidate`，保留已有单帧作回退。浏览器、自动校验与实施者视觉检查不能冒充 owner 美术验收。新增行为表现仍用现有 13 个语义，不创造新的任务真相、未读计数或完成事件。权限和实际错误始终可见。

## 已有基础和缺口

两态各 13 个行为中有 11 个仍是单帧，只有 blink/wake 是帧序列；两段明暗转场各八帧已存在。正式陪伴窗已经接真实 presence、pet 端点和权限卡。旧 animation-lab 鱼缸已退休，不作为本批产品入口。

已复现两条缺陷：首次可读完成基线为空时漏播下一次真实 done；permission 可被 receive 等低优先级单次动作覆盖。隐藏窗口仍运行画面计时器，系统减少动态只在启动时读取。浮窗目前只支持缩放、拖动、关闭和权限卡，缺少回主界面入口。

考虑过只增随机表演、全新骨骼运行时、扩充现有帧包三条路。选择第三条：复用冻结 rig 和 manifest，使素材可追溯、可回退，避免另建渲染系统。功能优先解决真实动作漏播、低打扰和快捷入口。

## 交付范围

1. 用测试修正首次完成和状态优先级，保持初次打开不重播旧结果、重连不重播、重复轮询只播放一次。
2. 增加动态 motion 控制：跟随系统减少动态，用户可主动减少动作；可「安静一小时」，期间停止装饰和庆祝，不积攒补播，保留真实连接与权限；隐藏时暂停画面定时器，回来按当前事实恢复。
3. 浮窗增加一个「找 CC」主入口，复用现有 show_main_window / pending navigate。保留拖动和缩放；键盘可用，浏览器预览有明确回退。
4. 扩充 thinking、working、permission、receive、done、look 等连贯序列：持续态首尾闭合，一次性态有收束，不移动固定脚底。只对已有 C 形变键和眼睛参数做小幅插值。素材量按视觉质量和机器负载决定，不以复制静帧充数。
5. 生产可用的动作目录、联系表和场景预览，支持并排看两态、真实 fps、减少动态、小尺寸与坏帧回退。素材、摘要、生成参数和验证结果可复查。
6. 首页复用同一个 manifest 与状态机，把已有 presence、对话 pending、attention 与 terminal 快照变成真实动作，不增加轮询。首次历史加载、重连、隐藏、切页及减少动态期间消费事件而不补播；权限优先。工作台 working→replied 仅表示「这一轮回复了」，不能宣称整件任务已完成；等待条目消失不代表成功。保留原来的暖纸、气泡和点击进入对话的入口。
7. 如果时间允许，补非运行时的视角/道具研究稿；不拿未完成或未验收内容替换现有 canonical。
8. 桌面陪伴记住正常关闭时的位置与尺寸，重新打开时恢复。显示器移走或缩放变化后要落在现有屏幕可见范围；尺寸继续遵守宽 200–600、高 250–750 逻辑像素。损坏/不可写的本地偏好不阻止开窗。在现有陪伴设置里保留一个「回到屏幕边缘」的次要恢复动作，不加入新页面、权限或依赖，也不改变 daemon 配置。
