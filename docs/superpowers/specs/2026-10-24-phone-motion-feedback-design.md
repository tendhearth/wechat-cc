# 手机原生动效与安静反馈

2026-10-24。用户已认可 CC 动效与第三版界面小样，并明确授权接入 `apps/app`、统一其他状态提示。参考小样为本次聊天的 `cc-mobile-motion.html` 与 `cc-mobile-feedback.html`；本文件记录原生接线边界，不另设一轮设计批准。

## 目的与选择

默认安静；需要处理时在对应内容旁显示图标；解释与恢复动作按需展开。状态仍由真实连接、请求、回执和任务事件驱动。采用现有 React Native Animated 与打包位图图标，不引入动画引擎或新的原生模块。与另做 Rive/Lottie 动画、引入 SVG 原生渲染相比，这条路径复用现有资产和运行环境，代价是细线图标需提供足够分辨率的打包资源。

## 不变约束

- 页面继续使用现有暖纸、字体、单一深绿动作色；颜色只来自现有 tokens。
- CC 只用现有 canonical 两张原图，不改角色、几何和 PNG 字节。Light 仅在真实已同步在线时出现；演示和断线保持 Dark。
- 呼吸 4 秒、幅度 2%，围绕 (256,470) 落脚点；收到 440ms 单次，做完 640ms 单次，等你 360ms 单次后静止，重连 720ms 同几何淡变。
- 系统减少动态效果、App 后台、页面失焦时停止动作；事件以稳定身份去重，历史回填不重播。
- 状态图标统一细线，常用 18pt；发送/录音按钮至少 48pt，状态入口至少 44pt；保留完整无障碍名称。
- 录音小点静止；上滑 x 表示松手后取消；转写只进草稿。达到时限后原来的松手不能变成发送。
- 不确定与失败分开，不能用成功图标冒充已送达/已做完。
- 保留配对世代、请求身份、草稿原文和已有提交锁；不新增协议/API，不重启共享 daemon，不部署或推送 dev。

## 接线

1. 共用图标、减少动态效果/前后台/焦点控制、短入场、spinner、可点状态说明。许可随图标保留，运行不下载资产。
2. CC 的一次性动作由首页新消息、新完成事件、待决定项和真实连接恢复触发；首次读取历史只作为基线。
3. 聊天成功不常驻状态句；等回复在回复位置显示 loader；失败/不确定入口在消息旁，发送结果无对应回执时在输入区保留状态入口。详细原因、只读核对、明确重试分开。
4. 核对只读取 `GET /m/api/chat`。刷新 Promise resolve 不等于成功，未找到消息不等于未送达；读失败、有限历史和旧数据均不得转为成功或自动清草稿。
5. 录音以 mic/square/x/loader/arrow 和时长表示。无权限或未配置仍有可发现的说明与设置动作。
6. 审批保留原始操作、工作目录与锁定；确认后维持原有返回进展导航，并在仍停留的处理状态用 check + 简短标签表示本步骤结果。
7. 共用展开区块与发现卡使用约 210ms 高度/透明度变化，保持已读和外链语义。连接提示、加载、常见信息性占位统一收敛；真实阻断、陈旧/部分结果、撤销与恢复操作仍清楚可见。

## 验证与交付

组件和状态层测试覆盖只读核对、草稿/身份隔离、取消/转写不自动发送、动作去重/停止和说明入口。执行 App 测试、根 Bun/Node 两套、类型检查、模块边界及双平台 Expo export；有可用隔离模拟器时做原生界面验证。交付独立分支与提交，不把浏览器小样验证当原生真机验收。
