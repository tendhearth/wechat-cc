# 桌面主窗口：干净的一版

2026-11-22。只管桌面的宽窗口（左栏 + 右边一栏）。窄窗口、手机网页、手机 App 这次都不动。

## 主人的话

这一版是 11-22 一天里跟主人来回六轮原型定下来的。每一条决定后面都有他的原话：

- 「感觉画面不够干净，claude app相对而言就干净多了，设计上还是不够」
- 看过第一版（只做减法）：「可以的，我觉得方向对了，但还是不够好看，设计感不好」
- 看过第二版：「名字加一句 短且简洁的描述，稍微缩进点。好很多，光晕去掉，我理解这是工作模式，要克制。我希望做的和现有产品都不太一样，要有特色，毕竟是personal ai，不是codex，但之前也聊过，也许codex是用户的习惯模式」
- 看过第三版：「类似于claude 的recap，你那个有点太短了，短到不知道具体是什么。信，应该是本子上有回复，才有信？平时不打扰为主。不是每条都需要cc建议，我的想法是如果一段时间用户没有回复，cc才会总结这个类似于recap」「写的和说的都是楷体没问题，现在几种字体，就cc不一样也就行了，不会太乱？」
- 看过第四版：「小结5min写」「默认开，用户可以关，设置里」「cc记了一笔，做成小字，淡灰色那种感觉…或者干脆做成不一样的，有区别度。这个看你建议。不止是字体，还有框，或者手写体的感觉，框也是」，并举了 Excalidraw 的手写样子。
- 看过第五版：「其他我没意见」。只剩 CC 的字用手写还是楷体没定。

## 三条原则

1. **骨架照习惯。** 左边一列事、右边一条线、底下输入框，用过 Codex、Claude 桌面版的人不用学。常见的机制照常规做。
2. **干活的地方要克制。** 没有光晕，没有自己会动的装饰。颜色少，线少，小字少。
3. **特色只放在「CC 是个人」上。** 这扇窗口和别的 agent 工具不一样的地方只有三处，都不是装饰：
   - CC 有自己的字。它写的、说的用它自己那支笔，别的一律不用。
   - CC 会留便条。你一阵子没来的事，它写一段小结；在线里是一张手画框的便条。
   - CC 在场但不抢。小小地坐在左上角；本子上有回复时它拿着一封信。

## 分几步

| 步 | 内容 | 动哪里 |
|---|---|---|
| 一 | 界面：字、颜色和层次、左栏、对话、输入框、一件事的页面 | 只动桌面 |
| 二 | 图（实验）跟着换样子 | 只动桌面 |
| 三 | 小结：谁来写、什么时候写、存哪、在哪显示 | daemon + 桌面；动手前把做法单独给主人 |
| 四 | 信：本子上有 CC 的回复没看时，CC 拿信、「本子」那一行有一个点 | 看本子现有的数据够不够，不够再议 |

第一步做完，左栏每件事下面那一句仍是现在的内容（终端会话最近的话），只换样子；第三步之后才换成小结。

## 字

只有两种，加上给路径和命令用的等宽：

| 用在哪 | 字 |
|---|---|
| CC 写的、说的 | CC 的笔。默认是本子里「手写」那支（程序里已经带着的 `TH Pen Hand`）；做成一个 token，换成「楷」那支（`TH Pen Kai`）只改一处 |
| 其余全部：名字、agent 说的话、主人说的话、按钮、时间、状态 | 系统无衬线（`-apple-system, 'SF Pro Text', 'PingFang SC', …`） |
| 文件路径、命令 | 等宽（现有的） |

「CC 写的、说的」具体是这几处，别的地方不许用：

- 和 CC 的那段对话里，CC 的回复。
- 左栏「CC 在家」下面那一句家里的情况。
- 小结（左栏每件事下面的两行，和线里的便条）。第三步之后才有。
- 等主人定的卡片里，CC 的那句意见。

名字（「CC 在家」、项目名、图的中心）是标签，不算 CC 写的，用无衬线。

手写那支字面偏小，字号要比无衬线大一号：左栏的小字 14.5、便条 16.5、意见 15.5、对话里的回复 18.5。换成楷体时分别是 13.5、15、14.5、17。

宽窗口的主界面从此不用衬线。这改掉了 2026-10-01 定的「全衬线」在这扇窗口里的用法；别的页面（本子、记忆、回忆、信）不在这次范围里。

## 颜色和层次

沿用现有的色板，不造新的主色。新加的几个都是现有颜色的浅深变化：

| 名字 | 值 | 用在哪 |
|---|---|---|
| 桌面 | `#efeae2`（现有的 ground） | 整扇窗口的底、左栏 |
| 纸 | `#fdfbf7` | 右边那一张 |
| 浮起来的一层 | `#fffefb` | 输入框、等你定的卡片、图上的说明卡、菜单 |
| 浅底 | `#f3eee6`（现有的 rail） | 主人说的话的框、选中的底、状态标记 |
| 字 | `#2a2622` / `#70665d`（现有的 ink / ink-soft） | 正文 / 次要 |
| 淡字 | `#a89f94` | 日期、通知、时间 |
| 细线 | `rgba(42,38,34,.09)` 和 `rgba(42,38,34,.16)` | 纸的边、卡片的边，都是半像素 |
| 灰线 | `#d6cec2` | 图上不要紧的线、「停着」的点 |
| 铅笔线 | `#b9ae9f` | 便条的手画框 |
| 强调 | `#4f6b4f`（现有的 accent） | 等你定、发送、选中 |
| 在做 | `#b07a2a`（现有的 warn） | 正在做的点 |

层次只有三层：桌面 → 纸 → 浮起来的一层。右边的纸离窗口上、右、下各 8 像素，圆角 12，半像素的边加很轻的影子。左栏和纸之间不画竖线，靠深浅分。

不用光晕（现有的 glow 在这扇窗口里不再出现）。

## 左栏

宽 284。从上到下：

- **窗口按钮那一行**：收起左栏、后退、前进，位置不变。
- **CC**：46 像素的亮着的 CC（现有的那张图），不发光、不动。右边两行：「CC 在家」（无衬线 15，粗一点），下面是家里的情况（CC 的字）。整块是回到和 CC 对话的按钮，没有选中的底，只在悬停时有一点。
- **四行**：搜索（右边写 ⌘K）、本子、记忆、回忆。每行 30 高，前面一个 16 像素的线条图标。这四样原来在左栏最底下排成一行字，现在挪到这里。
- **「项目」**一行淡字。
- **项目**：每行是
  - 最左一个 6 像素的点：等你定是强调色，正在做是暖色加一圈浅晕，其余没有点；
  - 名字（无衬线 13.5）；没看过的加粗；
  - 最右是时间，淡字，平时不显示，悬停或选中才出现；
  - 名字下面是一段话，最多两行，比名字往里缩 10 像素。
  选中的那一行是一张小纸片（纸的颜色、半像素的边、很轻的影子）。
  「收起这周没动的」、拖动排序、行上的菜单这些现有的机制都留着。
- **最底下**：「更多」，点开是现有的那个菜单（设置、实验……）。

## 右边的纸

**顶上一行**（52 高）：名字（无衬线 15，粗一点），后面是 agent 的名字（淡一点），再后面一个状态标记——一个小圆点加两三个字，圆角胶囊：等你定是强调色的浅底，正在做是暖色的点，停着是灰点。不再写成「Codex · 停着」这样用点连起来的一串。实验开着时最右是「线 | 图」。和 CC 的对话那一页这一行是空的。

**几次会话**：名字下面一排页签，纯文字，选中的那个字变深、下面一条细线。只有一次会话时不出现。

**线**：正文一栏最宽 712，居中。

- 日期、系统通知（「Codex 已自动升级到…」这类）：居中一行淡字，12。
- 主人说的：靠右，浅底的框，右下角的圆角收小一点，无衬线 15。
- agent 说的：靠左，无衬线 15，行高 1.75，没有头像、没有框。
- CC 说的（只在和 CC 的那段对话里）：靠左，CC 的字。
- 「做了 N 步」：一行淡字加一个小箭头，点开是一个浅底的块，每步一行，动词加等宽的路径或命令。
- 等主人定的卡片：浮起来的一层。里面依次是一个强调色的小点加「这件要你定」、问题（无衬线 15.5，粗）、CC 的意见（CC 的字，有才显示）、为什么来问（淡字）、两个按钮（「允许」是强调色，「不允许」是白底细边）。

每句话前面都不放头像。

**输入框**：浮起来的一层，圆角 20。上面一行是输入的地方，下面一行左边是加号和「对谁说」，右边是语音和发送（圆的，强调色；发不了的时候是浅底灰箭头）。现有的每个按钮都留着，只换样子和位置。

## 图（实验）

- 铺在点阵纸上：很淡的点，间距 22。
- 中心是一张小纸片（浮起来的一层），名字无衬线 15 粗。
- 分支标签是纯文字，前面一个表示状态的小标记（按状态时）；标签不画框。
- 线只留两种有意思的颜色：没解决的是强调色，在做的是暖色，其余是灰线。线比现在细。
- 点一条：左下角浮出说明卡——这句话、状态标记加出处（「Claude Code，11 月 18 日提交」这样一句话，不用点连着）、原话（左边一条细线）、「挪到」的几个小按钮、右上角「去线上看」。没选中时底下居中一行淡字提示。
- 右下角一个「回到中间」的小按钮。
- **分支标签的内边距上下各留 6 像素。** 画图的库在拖动时是拿指针上下各 12 像素去探节点的，标签矮于 25 像素就落不进「放进这一支」。

## 小结（第三步）

主人要的是像 Claude Code 里 recap 那样的东西：具体到看得懂，而且只在你一阵子没回的时候才写。

规矩（前三条是 Claude Code 文档里写明的，照搬；时间按主人说的改成 5 分钟）：

- 一件事的一轮做完超过 5 分钟、主人又没在看它，才写。
- 这次会话至少来回过 3 轮。
- 同一段离开只写一次。主人回了话、定了事，它就收起来。正在跑的不写。
- 一段话，先说现在停在哪、要不要主人，再说来龙去脉。封顶 400 个字符。
- 默认开，设置里能关。

谁来写：

- **Claude Code 的会话不用另写。** 它自己的 recap 就在会话记录里：顶层一条 `{"type":"system","subtype":"away_summary","content":…,"timestamp":…}`。直接读来用，不花模型。
- **别家的会话**（没有这一条的）由 CC 调一次便宜的模型写，走私密通道，输入有界。

在哪显示：

- 左栏那件事的名字下面，开头两行。
- 点进去，线的最下面（等你定的卡片上面）是一张便条：上面一行淡字「你 38 分钟没来，CC 留了张条」，下面是完整的一段。

便条的样子：

- 框是手画的铅笔线，不是直线：沿着圆角矩形走一圈，每隔六十来像素取一个点，每个点抖两三像素，连成平滑的曲线；同样的办法再描一遍，第二遍淡一半。抖动用固定的种子，同一张便条每次画出来一样。不引新的库。
- 字是 CC 的字，颜色比正文淡一点；框和字都压得很淡——认得出是它留的，又不抢正文。
- 手画只用在便条这一处。等你定的卡片、输入框保持直线。左栏的小结不加框。

## 信（第四步）

- 只有本子上有 CC 的回复、主人还没看时，CC 手里才有一封信（现有的那张信封图，22 像素，在它右下角），「本子」那一行右边有一个强调色的小点。
- 有事等主人定不算信，那个看项目前面的点。
- 平时不打扰。

## 没做的

- 窄窗口、手机网页、手机 App。
- 本子、记忆、回忆、设置这些页面自己的样子。
- 「连着的事」。
