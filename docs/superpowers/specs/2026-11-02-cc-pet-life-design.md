# CC 桌宠的生活与动作衔接

主人 2026-11-02 批准三项：生活动作；拎起、晃动、落地反馈；发现任务、准备、工作、收起、完成的连贯表达。参考朋友的 ClawdPet 感觉，保留 CC 发光小团的形象。主人明确要求直接完成，中途不再询问。

## 目的

让 CC 在安静时像住在桌边的小伙伴，在做事时让人读懂动作。真实任务与权限永远优先，动画不产生任务、消息、审批或自动重试，不用模型逐帧决策。

## 实现选择

沿用当前小透明窗口、CC 原始身体帧和独立道具，增加本地动作编排与软体姿态。未选全屏透明层：这三项不需要覆盖整屏或接触其他软件窗口。未选另造角色/直接搬参考素材：保留 CC 自己的轮廓与美术。行为与动画由本地规则驱动，真实工作事实沿用现有桥接。

## 生活

- 可见、已连接、lit、无任务/权限/提示、无悬停和键盘交互时，隔 20–40 秒选择探头、伸懒腰或短走；不连续重复。连续安静 3 分钟可打盹。
- 短走仅在用户已把窗口放在当前显示器底部附近时发生，横向不超过原位置 48 逻辑点，约 3 秒往返；起步、步态、收步连贯。屏幕中间原地生活，不自动搬家。
- 窗口临时自主位置与用户保存锚点分开；停止、关闭、退出、重开均不能保存临时位置。短走不跨屏、不读取其他软件窗口或全局光标。
- 整个浮窗被指向、键盘聚焦、开始拖动、打开设置、出现任意任务、权限或断连时立即停止自主动作。重新安静后重新计时。

## 身体与工作

- 原始 CC 身体帧保留；在独立身体层加入轻微倾斜、拉伸、重心和弹跳，脚底锚定。拖动速度驱动有界晃动，松手且实际移动后短暂下落、压缩、回弹；单击与取消不伪造落地。不改变任务点击行为。
- 新工作：准备/拿出电脑约 350ms → 真实 working 循环。离开工作：收起电脑约 300ms → 新事实。只有真实 done 才庆祝；取消、失败、初次观察和重新可见均不制造“完成”。
- 权限、错误、断连、新任务、重新拎起立即取消旧装饰过程。安静、减少动态、不可见时立即停止生活/身体运动；真实文字、道具与任务入口保留，回来不补播历史动作。
- 无情绪债、孤独值、打卡、催促、花园或换装；不加外部 Codex/Claude hooks。
