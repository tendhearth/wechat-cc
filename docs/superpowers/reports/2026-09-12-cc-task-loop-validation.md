# CC 单任务入口：实现与验证记录

日期：2026-09-12。范围：`2026-09-12-cc-task-entry-scope.md` 的第一段。

## 交付边界

正式「一起做」采用项目任务列表与连续对话两栏。Claude / Codex 回复直接进入当前任务，文件和工具记录按需展开。执行中输入保存在本任务草稿里，明确提示本轮结束才可发送。待决权限来自当前执行实例，操作与任务、请求编号绑定；列表只有在真实待决时显示“等你确认”。

按用户随后确认的方向，进入工作页自动收起「此刻／一起做／回忆」全局导航，只留左上角 CC 按钮打开临时导航。Escape 和点击遮罩关闭；返回生活页恢复完整导航。该按钮不启动或切换执行任务。重复选择“一起做”不会重建工作页；离开再回来保留原任务或新建任务模式及最新草稿。实际浏览器已验证这三条路径。

Paseo 的后台会话连续性、Orca 的项目边界与成果核对、CC Switch 的既有配置复用分别落实到后台持有任务、任务独立记录/文件快照、使用本机已登录工具。没有把三个产品的全部面板搬进页面。

当前仍一次执行一个任务。并发目录隔离、外部 CLI 历史导入、显式跨执行者交接、差异查看与完整 subagent 树尚未交付。现有 native 会话编号得到保留，不保证其他桌面 App 自动展示它们。

## 权限与会话

- Claude 使用现有 trusted / solo / strict 工具策略，将需确认的操作交给本任务的权限卡；普通聊天权限队列保持原样。
- Codex 工作台改用独立 app-server JSONL 接口，普通聊天仍使用原 SDK。核对实际返回的工作目录和生效策略；采用 on-request / workspace-write，禁止继承免审批设置。
- 权限请求只存在于内存中的当前运行实例；五分钟到期、取消、异常、关闭时拒绝并清理。历史审计不能重新变成可批准的请求。超长或未知权限形态拒绝，不截断后放行。
- 不注入陪伴记忆或其他任务对话，禁用消息/记忆 MCP、插件与 hooks，不改用户配置。保留工具本身的认证配置。
- **文件访问边界：**这些是当前系统用户启动的原生代理。workspace-write 限制写入，不代表只能读取所选目录；任务上下文隔离也不等于系统用户级文件隔离。没有实现对任意本机文件读取的独立安全沙箱，不应以此承诺凭证或私人文件无法被代理读取。
- 实测发现 Claude 项目目录把所有非字母数字字符替换成横线，长目录采用 200 字符前缀加原始路径哈希。修正恢复探测，避免含下划线的用户目录被误判为历史不存在。

## 实际执行验证

使用独立开发任务库和专用临时文件夹，只有三条人工销售记录与可丢弃测试文件。没有接通微信、修改用户项目或读取私人消息。实际工具版本为 Codex 0.153.4、Claude Code 2.1.267。

| 检查 | 实际结果 |
| --- | --- |
| Codex 新建、生成文件、连续对话 | 总额 500、最高项 mug 275；生成 result.md；继续追问得到 55%，原生 session id 不变 |
| Claude 新建、生成文件 | 同样核对三条记录，生成独立 result.md，原始 sales.csv 未修改 |
| Claude 允许 / 拒绝 | 浏览器批准删除 disposable.txt 后文件删除；拒绝 decline-me.txt 后文件保留，未改写命令重试 |
| Claude 重启后续接 | 修正路径后继续同一 session id，未重新读取文件即可回答 500 / 55%；未再记录恢复失败的降级事件 |
| Claude 停止 | 浏览器停止正在生成回复的真实任务，状态先停止中再已停止，已知 session 进程退出，待决请求清空 |
| Codex 允许 / 拒绝 | 对专用本机 HTTP 常量响应服务执行 curl；页面允许后取得 `cc-task-loop-local-probe-ok`，拒绝后没有新增 HTTP 请求；该版本原生 cancel 决定结束本轮，未标为完成 |
| Codex 停止 | 在真实待决权限期间点停止，任务变为 cancelled、请求清空；记录的 codex 与 codex-code-mode-host 两个进程均退出；原 session id 保持 |
| 文件预览 | 浏览器从 API 读取真实 result.md 快照，显示核对数据；失败或停止后的已有成果仍可查看 |
| 任务切换 | 新任务草稿切走再回来保留；独立测试覆盖慢响应、A→B→A、权限/停止响应晚到、焦点和阅读位置 |
| 窗口布局 | 1440、900、414 像素浏览器检查无横向溢出，任务与输入控件可访问 |

Claude 曾尝试用前台 sleep 做停止测试，被原生工具规则拦截，因此没有将该尝试算作停止成功证据；实际停止证据来自随后的真实模型生成。

Codex 实测还发现本机审批包含 `environmentId: "local"`，旧判断误拒绝该请求。按实际 wire 消息补回本机环境支持，仍拒绝其他未知环境；仅使用本次 `accept`，不应用策略修改。拒绝时遵守其可用决定列表：未提供 decline 时回复 cancel。对未知审批明确报错，不让它静默呈现为用户拒绝。临时抓取仅限已知测试命令的审批字段，未记录认证或其他 RPC 内容，诊断包装器没有进入仓库；最终验证使用原安装二进制。

## 回归验证

18 个定向测试文件、249 项通过；全仓 typecheck 通过。Tauri 精确代理路由测试编译通过。现有 vendored Marked 缺 source map 的告警仍存在，不影响运行。

独立审查发现并修复了：权限取消竞态、Codex 写入失败未收敛、过宽批准说明、工作目录未核实、配置继承、页面跨任务慢响应、加载时草稿丢失、刷新时焦点滚动。固定美术资产未修改。

本轮浏览器使用真实后台，不是静态交互样板；没有重新打包完整原生 App，不能把浏览器布局检查记为原生全量验收。
