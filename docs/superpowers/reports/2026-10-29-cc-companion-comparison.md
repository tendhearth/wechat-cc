# CC 动画与陪伴功能对照

核对日期：2026-10-29。依据是下列产品的官方网页声明，本轮没有安装这些产品或测试其后台实现。右栏是对 CC 的设计判断与实施方向。

## 双态是主线

CC 的两个维度分开表达：

- **形态**：Light / Dark 由真实连接决定。Light 是柔和瓷色与克制内光；Dark 是炭黑哑光、清楚的轮廓与白眼。页面一直用暖纸，两种形态不跟系统浅深主题切换。
- **行为**：想、做、等你决定、收到、回复、轻轻张望等来自已有语义。真实断连时保持安静的 Dark，素材库里的配对工作动作只是完整美术能力，不宣称离线时后台仍在工作。

这轮所有新动作都制作配对 Light / Dark，同画布、同几何 mask、同播放进度。审阅工具在同一张纸上并排显示两态，再用灰板检查透明边缘与对比度；灰板只是 QA 背景。

## 实施顺序

1. 先让信号可靠：初次历史不演成新结果，重复读取不重播，权限等待不被装饰打断。
2. 再扩素材：沿用冻结模型、相机和材质，以 C 的姿态为主、眼睛为辅，给持续态闭环和一次性动作收束。新增素材保持候选状态。
3. 增加可用性：一键回主界面、减少动作与安静控制；主页复用同一动作运行时和已有数据，不新加轮询。
4. 最后逐帧和小尺寸验收：两态、两种检查背景、48/96/128/256px、真实 fps、减少动态和坏帧回退一起检查。

不加入饥饿值、连续打卡、用户离开后的失落惩罚、随机声称已经办事或持续追逐鼠标。动作表达的重点是让人安心、看懂并接着做。
