# 微信成果文件交付

2026-09-13，`codex/cc-workbench-v1`。完成微信共用任务计划的 Task 5；前四项见[阶段交付](2026-09-13-cc-wechat-task-workflow.md)。本记录描述本地开发版本，不代表已推送、部署或真实微信账号验收。

## 已实现

任务结果列表给出每一份成果版本的获取命令：`任务 <任务编号> 文件 <成果编号>`。只有明确索取才发送；普通查询、任务完成及执行者写文件都不会自动推送附件。发送的是任务已保存并通过 SHA256 校验的原版本，最多 8 MiB。

文件请求保留原消息、账号、主人、任务、成果与内容摘要。重复请求复用回执；同一原消息改成另一项任务、文件或操作会被拒绝，不重新解释为新任务。历史补充和停止回执的标识保持兼容。

CDN 上传与最终微信消息发送分开记录。上传尚未产生可见消息，因此明确重试可重传；已上传描述符可以复用。最终发送只尝试一次，明确服务端确认才记接受；超时或响应不明保留“未确认送达”，不自动重放。已接受的重复请求不再发送文件或额外确认文字。审计来源为 `workbench`。

关闭会中止等待并阻止新的上传阶段、最终发送和迟到审计写入。原有 Bun CDN 编码约束仍保留：已经开始的原始 CDN 请求不能安全附加取消信号，但其迟到结果会被忽略，不会触发后续发送。这个限制不被写成“网络请求已经被物理终止”。
