# 工作台连续阅读与窗口草稿验证

日期：2026-09-12。范围：已有两栏工作台的阅读连续性和刷新恢复，不改变执行、权限、项目隔离与模型配置。

## 行为

- 已在末尾阅读时，新回复跟随到末尾。向上翻阅旧内容时，保持阅读位置，只出现“有新内容”按钮。
- 展开成果或操作记录时也保持阅读位置；点击新内容按钮才收起这两处并回到最新内容。各任务分别记录阅读位置与未读更新。
- 草稿输入即时保存到当前窗口的 `sessionStorage`，按任务或新项目独立存储；刷新后重新进入“一起做”，恢复所选任务、搜索条件和草稿。
- 草稿只包括文本、文件夹、名称与执行者选择；不持久化权限决定、续接令牌或交接令牌。刷新不发送消息、不启动执行者。
- 提交成功后沿用已有规则，只清除确实发出的草稿；请求途中新增的文字保留。存储不可用时退回当前页面内存，不承诺关闭窗口或应用重启后仍在。这不是跨设备草稿同步。

3. 点击按钮，滚动到2107；可视高度455，正好到达内容末尾。按钮隐藏。
4. 切到第二项任务，输入专用草稿，立即刷新；选中的仍是第二项任务，草稿逐字恢复。再打开第一项，输入框为空，未串入第二项文字。
