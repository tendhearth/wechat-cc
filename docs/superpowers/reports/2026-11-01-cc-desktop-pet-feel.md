# CC 桌宠陪伴感与轻交互

2026-11-01。依据[已批准设计](../specs/2026-11-01-cc-desktop-pet-feel-design.md)与[执行计划](../plans/2026-11-01-cc-desktop-pet-feel.md)，从 dev `3fba7813` 开始实施。root 是唯一写入者和整合者；探索与评审只读。日常机器仅编辑、读取部署前状态、保存完整签名包备份与最终签名/部署，不运行测试、构建或 GUI 自动化。

## 行为变化

- 工具排平时收起，靠近、聚焦或菜单展开时出现。隐藏时不接收鼠标；触摸环境保留入口。权限卡继续独立可见。
- 单击角色或按 Enter/Space，通过同一个现有命令进入聊天。3 点移动阈值、拖动合并、确认后保存、取消与失焦恢复均保留；真实拖动和丢失鼠标抬起不会误开聊天。
- 空闲时的靠近/聚焦回应复用本形态的 look，成功播放后冷却 12 秒。工作、权限、转场、安静、减动、隐藏与销毁后均不插入或积攒招呼；形态、事实道具与未读数不变。
- working/thinking 每轮动作结束后，在首帧分别维持 6/9 秒，再继续。休息只影响精灵播放，真实任务状态持续可读，状态变化立即撤销旧节奏。
- 当前文字按权限、真实连接异常、真实未读内容、工作状态排序。装饰动作不被当作任务失败或完成。
- 主窗重建时，导航等待 dashboard 真正可见再聚焦输入框；事件监听移到供应商配置加载之前。新的实时导航优先于较旧的异步 pending 返回。

角色图片、冻结模型、材质与两态连接定义均沿用原内容。这轮参考交互关系，未复制竞品素材。

## 已取得的开发回归

所有测试在 Mac mini 上、以隔离状态执行。原 Home’s Mini 网络不可达，新建 Homebot’s Mini 的独立 lab，并同时遵守家族检查锁。公开工具准备与依赖下载单独记录；测试阶段仍拒绝外连。

| 精确主机/路径/端点/SSH 边界 | 12 项通过 |
| 手势、真实页面接线、状态文字、导航、pet、renderer 与 QA 打包 | 157 项通过 |

新需求先观察失败再实现。持续动作最初的采样点恰好与旧循环同相，已先修正测试、在旧代码上重新取得真实失败，再实现休息节奏。主窗时序在浏览器复现“聊天已显示但未聚焦”和“供应商加载期间事件未接收”，修复后各启动时序均通过。独立评审没有严重或重要问题；另发现的“监听注册期间收到实时导航、随后旧 pending 返回”边界已先复现失败再修复，新增回归通过。

工具排旧用例更新为先靠近再操作；不使用强制点击或放宽隐藏时的命中规则。一次首页检查停在 load 等待、未触达功能断言，改为 DOMContentLoaded 后继续要求 dashboard/runtime/form 就绪，保留原来的行为断言。

## 原生与部署验收

原生 QA 继续通过应用内 WebKit 驱动，读取实际 AppKit 窗口几何与导航回执。合成 DOM 事件不代表硬件鼠标投递。透明区域穿透须有单独的系统投递与恢复证据，本批生产输入路由保持原机制；该项不能用浏览器 elementFromPoint 或窗口样式通过代替。

完整全量回归、原生 QA、生产包构建、独立评审、合入与部署分别留实际回执。操作记录位于本计划的忽略目录 `.superpowers/sdd/2026-11-01-cc-desktop-pet-feel/`；最终交付以相同提交的 CI、构建摘要、部署回执及运行中健康版本为准。
