# CC 工作台专注布局验证

日期：2026-09-12。基线：`7cd6299d`。范围为既有工作台的呈现与阅读状态，不包含新的执行协议、历史导入或跨执行者交接。

## 呈现变化

- 项目下的任务收成两行：标题，以及执行者与状态。更新时间保留在提示/可访问名称中；完整路径保留在项目提示和任务详情中。同名文件夹仍显示父路径消歧。
- 标题、短项目名、执行者与状态保持可见。任务编号、完整路径、更新时间和可用时的微信续接收进“任务详情”。删除工作顶栏口号，减少大标题、彩色胶囊与卡片阴影。
- 当前任务使用固定头部、独立滚动的完整对话、独立底部输入区。成果与工具日志保持按需展开；没有成果时不再显示空成果区域。
- 运行或排队时保留可编辑草稿、明确发送时机与停止按钮；完成后在同一位置继续。没有增加即时传达草稿的假承诺。
- 当前权限请求显示在输入区上方，完整描述可阅读。长说明区域限高滚动，同一请求集合的阅读位置不会被刷新重置；新增/移除请求时回到顶部，跨任务分别保存。
- 工作台的样式集中到 workbench.css，删除 cc-life.css 中互相覆盖的工作台规则。暖白纸色、深色正文和少量橄榄色强调延续 CC 风格。

设计参考为官方 UI 源码，精确链接见 [实施计划](../plans/2026-09-12-cc-workbench-focus.md)。未把源码阅读表述为已运行其他三个产品。
