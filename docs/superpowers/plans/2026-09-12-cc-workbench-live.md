# 一起做真实连接

沿用已确认的 presence 页面，不增加入口或表单。本轮补连接，验证已有工作台闭环。

1. 修复开发页缺失的七条 workbench 代理。宿主保管凭据；mock 不访问真实后台；默认开发模式禁写，写操作需显式启用；拒绝跨站、未知路径。先加回归测试。
2. 提供独立开发启动方式，复用生产 SQLite store/service、Codex adapter、内部 API。任务状态放在独立目录；生活页面继续读当前 daemon。只为一起做启用任务写入，不重启微信服务、不开放其他修改。
3. 从页面提交合成文件任务，真实生成成果、读取确认、续接同一任务；检查旧版哈希与输入不变。验证重启后任务保留。
4. 跑定向测试、类型检查、独立审查；记录实际运行边界，提交。

这一步只接已有任务引擎，不宣称多助手自动复核或接管用户现有会话。原生 app 仍需跟随同版本 daemon 发布。
