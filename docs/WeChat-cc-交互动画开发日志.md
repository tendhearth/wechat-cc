# WeChat-cc｜交互动画开发日志

> 这份笔记记录动画实验的设计决定、已经完成的交互和待验证项；每次调整后在文末追加一条记录。

## 当前体验

- 场景：陪伴中的鱼缸插画。静态底图不再包含可动角色，以免动画产生重影。
- 小鱼：不同颜色的小鱼均为独立图层；在水面下自然游动，鼠标进入水域后会逐渐聚集，移开即恢复正常游动。
- 性格：橙色鱼更大胆、靠近更快；粉色鱼慢热；蓝色鱼最容易被惊动。
- 逃跑：触碰单条小鱼时会快速逃开；水域内点击一次，所有鱼会四散逃开。
- 边界：小鱼与鼠标互动始终被限制在水面以下、泥土以上的真实水域。
- 水草：每株水草独立，整体缩至原视觉尺寸约 80%、贴近底部泥土；长叶水草摆动幅度更大。
- 底部花朵：由静态整图改为叶片底座、固定花芯、最大的中央固定花瓣与三组左右镜像花瓣；花瓣由中心向两侧逐级变小，所有花瓣共用花托根点，鼠标悬移时收拢为总共 20° 的含苞夹角，移开后向外展开。
- 气泡：水中会持续上浮大小不一、带轻微横向漂移的气泡；使用棕色、轻微不规则的双层手绘描边。
- 小熊：完整透明抠图独立于静态插画；鼠标靠近会有轻微呼吸、抬起与注视反馈。鼠标首次移入小熊区域时，独立前臂会以肩膀为固定点抬起并连续挥手。

## 技术选择

当前 Demo 直接在 WeChat-cc 的「动画实验」中以 Canvas 运行：适合快速验证互动、无需手动学习动画软件。

- 采用分层 PNG + Canvas 关节旋转，能快速得到自然的点击反馈。
- 关节为肩膀固定点，独立前臂围绕该点旋转；后续若要制作更丰富的表情、全身动作，可把相同分层素材继续交给 Rive，使用骨骼、网格和状态机制作可复用动画。
- 当前实现不依赖 Rive 编辑器，因此不需要手动制作 `.riv` 文件。

## 素材台账

- 小鱼：用户提供的手绘透明小鱼，以及从原插画中拆出的不同颜色鱼。
- 水草：从原插画中拆出并按单株独立绘制。
- 小熊身体：完整透明小熊抠图，保留正常比例。
- 小熊前臂：AI 生成的同风格透明前臂，用于肩膀固定的挥手动作。

## 更新记录

### 2026-07-14｜小熊骨骼挥手实验

- 开始将小熊从“整张图轻微倾斜”升级为分层木偶。
- 新增独立的水彩风小熊前臂素材，准备用固定肩点驱动挥手。
- 已完成：点击小熊后，手臂从放松姿态抬起、连续挥动后回落；动作由固定肩点驱动，避免整图旋转、手臂脱节和比例变形。
- 调整：前臂改为身体前层，并将肩点由耳侧下移至上半身，修正了手臂看似从背后挥出的方向问题。
- 分层重构：身体层完全移除手臂和小鱼；独立前臂保留黄色小鱼，按原图右侧肩膀位置覆盖并挥动。身体层脚部曾被重新绘制得不一致，现已替换为保留原图坐姿与脚部关系的版本，待视觉确认。
- 位置微调：按页面显示尺寸将“拿鱼手臂”整体向左移动 50px、向下移动 80px，肩膀旋转行为保持不变。
- 触发方式：挥手由点击改为鼠标首次移入小熊区域触发；停留期间不重复重置动作，移开后再次进入可重新挥手。
- 气泡质感：加入暖棕色、轻微不规则的双层描边，使上浮气泡更清楚地融入手绘插画风格。
- 花朵交互：将原整朵静态莲花替换为独立叶片、独立固定花芯、最大的中央固定花瓣和三组镜像花瓣。中心花瓣与花芯不参与开合，向两侧的花瓣逐级变小；所有花瓣根部固定在花芯下方同一点。悬移时以该点收拢，并在闭合状态保留总共 20° 的含苞夹角；移开后以较慢速度展开，同时暂停该区域的小鱼跟随提示以避免交互冲突。
- 花朵展开角度：加大三组活动花瓣的展开扇形，使外侧更舒展；根部、中央固定花瓣与花芯保持不动，闭合总夹角仍为 20°。
- 花朵尺寸：叶片、活动花瓣、中央固定花瓣与花芯均以花托为锚点统一缩小 30%，悬移命中区域同步收紧。
- 手臂质感：不重绘原素材，只保留肩膀根部的局部网格形变；根部约增加 26% 宽度，并沿前臂平滑收回至原始粗细。手掌与小鱼不变形，肩膀关节仍随同一图层运动。
- 挥手触发：鼠标移入小熊区域与从小熊区域移出时，都会完整挥手一次；区域内移动不会重复重置动作。
- 小熊萌化：替换为无手臂萌化身体层，右侧脸颊改为圆润外轮廓；头部视觉增大约 15%、躯干相对缩小约 15%，保留坐姿脚部与拿鱼手臂的独立关节。
- 小熊整体尺度：身体与拿鱼手臂以脚底为共同锚点统一缩小 15%，保持坐姿落地与肩膀连接，不会缩小后悬在泥土上方。
- 拿鱼待机姿势：保留举着小鱼的动作语义，将手臂默认角度顺时针收低约 8°，让小鱼停在脸颊／胸前高度；悬移挥手仍以该姿势为起点。
- 小熊文字绑定：气泡文字改为按小熊脚底锚点与缩放比例计算位置，固定在耳朵上方留白处，不遮挡耳朵；小熊身体、拿鱼手臂、文字、注意力光圈与悬移区域作为一组整体向右移动 20px。
- 小熊肚子质感：不重绘身体素材；在身体中下段使用局部网格把左右轮廓柔和向外推，使肚子更圆。原身体层作为无缝水彩底层，消除网格三角片的拼接线，头部、脚部和手臂连接区域不变形。
- 螃蟹彩蛋准备：新增大眼、圆身体、举钳的水彩风透明螃蟹素材，保留用户参考图的角色特征并融入当前暖棕描边插画风。拟定交互为点击指定水草后，从鱼缸底部出现、沿鱼缸侧壁爬过水面，再延续至页面外；尚待接入动画逻辑。
- 验证：鱼群互动、小熊点击反馈与挥手画面均已通过浏览器自动测试。
