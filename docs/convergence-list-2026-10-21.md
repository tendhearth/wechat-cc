# 收敛清单(2026-10-21,等主人点头)

主人 10-20 定的方向:**微信保持对话聊天和简单做事;整体掌控、多 agent 交给软件(桌面 / App);少用的功能放进可选模块、默认关;删之前先给主人看清单。**

这一页分两半:**上半是功能模块**(哪些默认关、哪些删),**下半是手机网页**(哪些页面 / 路由删)。每一条都写清:你会看到什么变化、数据会不会丢、要你定的是什么。**你点头之前,代码一行不动。**

> 说明:仓库里现有的「插件」机制只管外接的 MCP 服务(比如 wxvault),下面这几样都是 daemon 里自带的功能,没法直接变成那种插件。所以这里的「进插件」指的是:**收进一个独立的可选模块,有一个开关,默认关;关着时它的入口(微信命令、桌面那一栏、手机那一块)都不出现,后台也不跑。** 数据一律只是「睡着」,不删 —— 除非下面写了「删」。

## 你点头之后怎么做

- 每一条单独一个 PR,先做「关得掉」(开关 + 入口跟着开关走),再做「默认关」,最后才删代码;删之前跑一遍完整测试。
- 你这台机器上已经开着的,一律保持原样,不会因为改默认值而被关掉。
- 改完的版本照常部署、自检;要是哪个关掉以后你发现其实要用,说一声开回来,数据都在。
