# 手机端用词表(App 与手机网页共用)

> 2026-10-20 定。起因:手机端现状盘点发现同一件事三处三个说法(「允许这一步 / 允许 / 允许这一次」、「等你决定 / 等你批准」、「正在整理 / 进行中 / 在跑」)。改界面文字时以这张表为准;对外命名仍按 [产品命名规范](product-naming.md)。
> 此刻的三组分法(等你 / 在做 / 做完)借鉴 Paseo 的 Ready to review / Working / Done 与 GitHub Live 的单一状态词。

## 拍板(权限卡、问题)

| 场合 | 用 | 不用 |
|---|---|---|
| 同意按钮 | **允许这一步** | 允许 / 允许这一次 / 同意 |
| 拒绝按钮 | **先不做** | 拒绝 / 不允许 |
| 按钮下的小字 | **只对这一次请求** | |
| 按钮顺序 | 先不做在左(次要),允许这一步在右(主按钮) | 允许在左 |
| 已经被别处拍过 | **已在别处处理** | |

## 状态(一件事 / 一起做的任务 / 终端会话共用一套)

此刻页按这三组分,每组一个衬线小标题;只有「等你」用强调色,其余 ink / 灰。

| 组 | 状态词 | 对应的内部状态 | 不用 |
|---|---|---|---|
| **等你** | **等你决定** | 待批权限、执行者提问、额度用完等你选 | 等你批准、需要你、待处理 |
| **在做** | **在做** | queued / running / 终端 running | 正在整理、进行中、在跑、处理中 |
| **做完** | **这一轮做完了** | 一起做 replied(还能接着说) | 这一轮已回复、已答复 |
| | **完成** | matter / 任务 completed | 事情完成、已了结 |
| | **没做成** | failed | 失败了 |
| | **停下了** | cancelled / interrupted | 已停下、中断了 |
| (不进三组) | **歇着** | 终端会话 idle(会话还在,没在跑) | 空闲 |
| (不进三组) | **结束了** | 终端会话 session_end | |
| (不进三组) | **已归档** | archived | |

## 连接

| 场合 | 用 | 不用 |
|---|---|---|
| 电脑连不上 | **家里的电脑暂时连不上** | 连不上 CC、暂时连不上家里的 CC |
| 看到的是旧画面 | **你看到的是 HH:MM 的样子** | 这是上次留下的画面 |
| 电脑睡着 / 中继不在(App B3) | **电脑歇了,事情先停着**;CC 变暗,不用红色 | 出错了、失败 |
| 这台设备被撤销 | **这台手机已经不能连了,在电脑上重新配对** | 从微信重新打开 |

## 名字

- 页面标题、顶栏:**CC**(网页 `<title>` 也是 CC)。不写「随身 CC」。
- 主人的电脑:**家里的电脑**(网页里不要把电脑叫成 CC)。
- 「一起做」「此刻」「CC 眼中的你」「CC 的信」沿用。

## 不用的东西

- emoji(#369 定的;网页 home.js 里残留的一并去掉)。
- 强调色只给「等你」那一组的标题、主按钮和 diff 的加行;状态文字本身不上强调色。
