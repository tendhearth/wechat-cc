# 手机端用词表(App 与手机网页共用)

> **2026-10-28 原生手机设计更新**：主人确认极简稿并要求接入。这里的状态词继续用于详情与无障碍说明；原生列表可用有完整标签的状态图标、分组和具体操作标题承担表达，不再在每行重复“等你决定 / 在做”。完成记录在此刻收为勾号与数量，时间范围、完整计数和部分数据详情点开查看。未确认、失败、停止、旧数据、授权范围等必要区别仍保留短文字。浏览器端跟随其已实现界面，不据此宣称已同步改版。设计见 `docs/superpowers/specs/2026-10-28-phone-minimal-design.md`。

> 2026-10-20 定。起因:手机端现状盘点发现同一件事三处三个说法(「允许这一步 / 允许 / 允许这一次」、「等你决定 / 等你批准」、「正在整理 / 进行中 / 在跑」)。改界面文字时以这张表为准;对外命名仍按 [产品命名规范](product-naming.md)。
> 三组分法(等你 / 在做 / 做完)借鉴 Paseo 的 Ready to review / Working / Done 与 GitHub Live 的单一状态词,**用在「一起做」的列表上**;「此刻」照主人 10-05 定的「每样东西只有一个家」(spec 2026-10-05-now-together-hierarchy)只放「等你」那一组,不重复一起做的列表。

## 拍板(权限卡、问题)

| 场合 | 用 | 不用 |
|---|---|---|
| 同意按钮 | **允许这一步** | 允许 / 允许这一次 / 同意 |
| 拒绝按钮 | **先不做** | 拒绝 / 不允许 |
| 按钮下的小字 | **只对这一次请求** | |
| 按钮顺序 | 先不做在左(次要),允许这一步在右(主按钮) | 允许在左 |
| 已经被别处拍过 | **已在别处处理** | |

## 状态(一件事 / 一起做的任务 / 终端会话共用一套)

「一起做」列表按这三组分,每组一个衬线小标题;只有「等你」用强调色,其余 ink / 灰。「此刻」只出现「等你」那一组。

| 组 | 状态词 | 对应的内部状态 | 不用 |
|---|---|---|---|
| **等你** | **等你决定** | 待批权限、执行者提问、额度用完等你选 | 等你批准、需要你、待处理 |
| **在做** | **在做** | queued / running / 终端 running | 正在整理、进行中、在跑、处理中 |
| **做完** | **这一轮做完了** | 一起做 replied(还能接着说) | 这一轮已回复、已答复 |
| | **完成** | matter / 任务 completed | 事情完成、已了结 |
| | **没做成** | failed | 失败了 |
| | **停下了** | cancelled / interrupted | 已停下、中断了 |
| (不进三组) | **歇着** | 终端会话 idle(会话还在,没在跑) | 空闲 |
| (不进三组) | **结束了** | 终端会话 session_end | |
| (不进三组) | **已归档** | archived | |

## 连接

| 场合 | 用 | 不用 |
|---|---|---|
| 电脑连不上 | **家里的电脑暂时连不上** | 连不上 CC、暂时连不上家里的 CC |
| 看到的是旧画面 | **你看到的是 HH:MM 的样子** | 这是上次留下的画面 |
| 分不出是电脑那头还是手机这头的问题(App 现在就是这样) | **家里的电脑暂时连不上**(有同步时间再加「· 你看到的是 HH:MM 的样子」);CC 变暗、灰点,不用红 | 电脑歇了、事情先停着(可能是假话:手机没网时电脑上的事还在做) |
| 确知电脑那头没连上(中继报对端离线之后才有,App B3) | **电脑歇了,事情先停着**;CC 变暗,不用红色 | 出错了、失败 |
| 这台设备被撤销 | **这台手机已经不能连了,在电脑上重新配对** | 从微信重新打开 |
| 页面还拿着退休了的 v1 / 老中继的配对(2026-10-25 F4) | **连接方式升级了，请在电脑上重新扫码配对**(下面一行小字:在电脑上点「连接手机」，用这台手机扫出现的码。) | 协议版本不兼容、请升级、出错了 |
| v2 配对的握手被中途改过(中继剥掉了版本,客户端拒绝降级、自己按退避再试;配对不动) | **家里的电脑暂时连不上（连接在半路被改过），过一会儿会自己再试** | 请重新配对(配对没坏)、连接被攻击 |
| 「CC 的连接」里:配置还是老中继、没有新中继 | **手机连接要换新中继，在「连接手机」里重新配对。** | 中继已退休、配置错误 |

## 名字

- 页面标题、顶栏:**CC**(网页 `<title>` 也是 CC)。不写「随身 CC」。
- 主人的电脑:**家里的电脑**(网页里不要把电脑叫成 CC)。
- 「一起做」「此刻」「CC 眼中的你」「CC 的信」沿用。

## 不用的东西

- emoji(#369 定的;网页 home.js 里残留的一并去掉)。
- 强调色只给「等你」那一组的标题、主按钮和 diff 的加行;状态文字本身不上强调色。
