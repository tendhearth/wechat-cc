# 任务内的同命令批准

工作台权限卡可选「本任务同命令都允许」；微信同一张卡回 `yt <两位码>`。普通允许仍只批这一步。只有服务端确认可复用时才显示新选项，不能由客户端自行指定范围。

临时许可沿用 `Rule`、`RuleWhen` 和 `matchRule`：`surface=workbench`、任务 `scope`、执行者、工具与 `commandHash` 必须相符。建立与复用都必须满足 `EDIT_REPORTING_PROVIDERS`；Cursor、自定义 ACP、未知执行者不能使用。规则只存在于当前运行的 `RunPermissions`，结束、取消、归档或重启后不继承，也不改全局 permission-rules.json。现有规则的拒绝、要求询问以及固定红线优先，规则服务失败时也不提供任务许可。

指纹包括实际工作目录、完整字面参数及已读取文件的路径与 SHA-256。只归一引号与 shell 识别的空格/tab；保留参数顺序、大小写和引号内空白。任务许可仅用于无代码委派入口的少量原生命令：在固定名单中再过既有低风险分类，另含 echo/pwd/true/false。缺少命令事实、环境赋值前缀、截断命令（执行者的 2000 字边界）、shell 展开/复合命令、未引用的 zsh `=command` 展开均不放行。git、rg、find、sort、wget 等能从参数或配置委派程序的工具也不在名单内。红线程序名与 macOS 敏感路径保守识别大小写及引号/转义变体，不合并参数大小写。

脚本通过工作区锚定读取，不跟随链接、不读工作区外文件、FIFO 或二进制；每份最多 128 KiB。`source ./helper` 与 `. ./helper` 的无扩展名入口同样读取。package alias 展示 package.json 与能解析到的实际入口。读取失败时卡片显示原因，脚本文本再过红线检查。

**预览是读取时的快照，不是执行字节保证。** 当前 Claude/Codex 审批通道没有消费不可变执行树的能力，Codex 只能向另一个进程返回 accept；批准时重读或在返回前再 hash 都不能消除随后打开路径的竞态。因此从本批准通道进入的解释器、source、package/build/test runner、未知程序、可委托其他程序的选项等入口，不建立任务许可，**单次允许与已有规则允许也不能放行**。卡片说明阻止原因，可拒绝，或改用原生文件工具、可核实的逐条命令。带额外授权或被截断的 Codex 请求仍保留这个禁止执行标记，不把它当作允许规则的命令事实；Claude/ACP 截断到 2000 字的请求同样被拒绝。解释器、import/source、测试配置、加载器、插件、PATH 和执行配置没有被冻结；在支持绑定完整执行依赖前，不宣称对这些入口完成了字节授权。现有执行者本来无需批准的档位路径不由本功能改变，也不在上述保证范围内。

卡片只携带每份脚本前 2000 字。展开时通过 `GET /v1/matter/permission-script`，以任务、待批请求、路径和 SHA-256 读取同一份内存快照，每块最多 8000 字。接口只给 operator/已配对设备，不给链接令牌；卡片了结后全文也失效，不提供任意文件读取。trusted/FILE 的 pet 与 presence 仅投影安全队列元数据，原始 prompt、活动里的待批说明和脚本文本都不返回。桌面批准卡通过宿主使用 operator 单独读取 admin 的 `GET /v1/permissions/pending`；未获得对应 hash 的授权详情、加载失败、条目消失时不显示可批准卡片，晚到的旧详情也不能覆盖新卡。

通知只带脚本路径、指纹和批准卡查看入口，不携带文件片段。无法绑定字节的内联脚本描述也不进入通知；所有通知入账前调用既有 `redactSecrets`，再按长度截断，发送端消费同一份脱敏后的正文。精确源码只留在内存快照与授权批准卡。

微信码与工作台共享到期时钟。网络守护暂停运行时，两边一起停表；任一端处理、取消或过期后，其他端随之收卡。图形自动化与原生构建由整合者在 mini 验证，本地只跑单测/组件及离线接线测试。
