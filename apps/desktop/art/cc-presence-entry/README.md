# CC：此刻与一起做

一个独立的交互样板，不修改现有页面。以仓库根目录作为静态服务根目录，打开
`apps/desktop/art/cc-presence-entry/preview.html`。

## 这次试什么

- 此刻只呈现 CC 当前的一件活动，以及与它说话的入口。用户说话后，CC 转为倾听。
- 一起做由 CC 统一汇报；每件事仅呈现当前阶段：正在推进、需要决定或已经完成。助手执行和原会话样例按需展开。
- 回忆承接昨天的画、过去的见闻和关于用户的记忆。样例记忆支持纠正和移除。
- 不同事情的阶段、决定、草稿和回复分别存储，生活对话也有自己的范围。

融合来自同一个 CC 的持续负责：它有自己的活动，也记得与用户一起做的事。不会为了展示能力，要求用户先浏览模型列表、配置表单或多份助手对话。

## 边界

所有活动、回复、执行和记录均为演示；刷新重置。没有后台绘画、真实模型调用、账号接管或真实原会话入口。复用冻结角色 PNG、实体 mask、已有 SVG 画作和图标，不新增角色资产。

下一步仍需验证真实数据下的简洁程度：多任务待决时如何排序、何时提醒、结果较大时如何就地查看。此刻不应展示编造的活动；无活动时允许 CC 安静待着。

## 本轮验证

- 新模型与共享范围模型共 9 项测试通过，全仓 typecheck 通过。
- 实际浏览器查看此刻、进行中、待决定、完成、回忆页面。
- 实际操作：任务决定独立推进、工作消息发送、成果打开、记录展开、Escape 关闭、样例记忆修改、个人草稿跨页面保留。
- 未验证真实模型执行、原生桌面打包或移动端视口。
