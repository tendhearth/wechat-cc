# 随身 CC · 此刻三状态（第二版）

可交互视觉样板，不接真实接口，不替换现有 `/m` PWA。所有任务、决定、时间均为演示数据；按钮不会提交真实审批或发送消息。

三种状态：

1. 普通此刻：CC 在画明信片，任务进展收成一行。没有任务计数和历史信息流。
2. 需要你：短场景、一件事、两个明确选择；理由折叠，没有其他任务卡片。选择后禁用重复提交，反馈明确是演示。
3. 带回成果：使用已有咖啡馆 SVG 明信片原图，点击放大、保存；来源和过程按需展开。不是新生成的成果，也不虚构检查通过。

保留「此刻／一起做／回忆」。顶栏去掉重复头像，设置使用明确的文字入口。后两个导航在本样板中只打开说明弹层，不代表完整页面已经实现。

使用冻结 Light / Dark CC 原资产。「重演：你来了」展示 Dark → Light 的到来事件，使用两图淡化表达设计意图，并非正式转场播放器；不按计时循环、网络或主题切换。支持系统减少动态效果设置。

## 断线与草稿

顶部可模拟断线：显示上次更新时间，禁用决定和发送，已有成果仍能打开。Light / Dark 外观不受连接开关影响。两个输入框独立保存草稿到当前预览站点的 localStorage，重连不自动发送；存储不可用时仅保留页面内草稿。

这只是断线状态演示。正式接入还需要服务端状态刷新、审批过期与重复提交处理，不能把切回在线等同于真实任务已重新验证。
